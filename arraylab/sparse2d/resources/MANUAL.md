# ArrayLab 二维稀疏阵列操作指南

从主工作台“分析 → 二维稀疏阵列”或F8打开。稀疏模块在同一程序内使用独立工作窗口，关闭后重开可保留本次会话结果。

## 操作顺序

1. 在左侧“阵列、单元、工况、高级”设置输入；预设仅载入设置，不自动计算。
2. “开始计算”生成规则抽稀、随机对称、贪心交换、模拟退火、重加权ℓ1等方案；中心禁布、多工况时另有固定支撑调幅对照。
3. 从方案表选择结果，切换当前工况、总场/阵因子/单元视图、理想/量化相位视图。图块可最大化，支持缩放、平移和单图保存。
4. “稀疏后加权”提供minimax LP、Taylor、Chebyshev、Gaussian、均匀权重；追加新行并保留原行，位置和数量不变。
5. “导出已计算结果”保存完整JSON、逐阵元/逐工况CSV、图片和离线HTML。已有目录不覆盖；新目录在全部成功后才发布。

修改输入后，旧结果继续使用已计算快照；左侧的待计算参数不会篡改旧方案的加权、图表或导出。计算期间禁止关闭主工作台，完成后可正常关闭。

## 主要设置

- 候选网格：Nx、Ny各为4–20的偶数，中心对称成对选点；K为4至候选数的偶数。
- 中心禁布：无孔、矩形孔或圆孔；尺寸以参考波长λ0计，圆孔使用X字段作为直径。
- 最小间距：二维欧氏中心距，以λ0计；0表示不追加约束。全部生成方案都检查间距和禁布区。
- 多工况：最多25个扫描角与频率组合；同一毫米布局和同一幅度向量参与所有工况。每个频率重新设置理想扫描相位，不是固定馈电网络的扫频模型。
- 单元：理想点源、薄线偶极子、贴片标量近似或标量CSV。导入单元的数据快照随结果保存，后续加权和导出无需重读原文件。
- 相位量化：0为理想，1–12 bit为理想综合后的固定布局复核；不进行量化感知优化。

## 送入平面阵电气设计

选好方案和显示工况后，点击“将所选理想布局送入平面阵电气页”。传递全部坐标、相对幅度、所选频率和扫描角，载入到平面阵输入，随后自行点击“生成平面阵设计”。已有电气结果保持不变。

此操作使用理想布局及幅度，创建50 Ω输入/节点/负载的并联初始网络和连续扫描补偿；这些阻抗是可编辑初值，不是稀疏综合得到的阻抗。原相位量化码不迁移，因为原工具量化绝对馈相，而电气页量化网络后的补偿电长度。两者的参考及半步取整规则不同。

仅各向同性点源且不超过200阵元、最大孔径40λ的方案可送入当前平面阵电气模型。幅度必须满足电气模型的正幅度和120 dB动态范围约束。非点源、超限或无效方案明确拒绝，不删阵元、不补零、不替换单元模型。

## 无头入口

`ArrayLab-cli.exe --sparse --help`查看完整控制命令，保留Sparse2D的schema_version=1设置和结果格式。

```
ArrayLab-cli.exe --sparse run --config examples/sparse-basic.json --output results/sparse01 --report
ArrayLab-cli.exe --sparse inspect --input results/sparse01
ArrayLab-cli.exe --sparse planar --input results/sparse01 --index 3 --case-index 0 --output results/handoff01
ArrayLab-cli.exe --planar-config results/handoff01/planar-config.json --output-dir results/feed01 --plot all
```

方案索引为0基；先inspect确认行索引，不要依赖固定方法顺序。`planar`另导出source.json来源记录及毫米坐标CSV。`weight`、`evaluate`和`batch`支持已保存结果加权、重新复核与批量任务。默认仅保存JSON，`--report`增加图表；不导入Qt，不依赖独立Demo目录。

稀疏子命令沿用原控制协议：最终成功或失败JSON写stdout，进度JSONL写stderr；退出码0成功、2输入无效、3目标已存在、1其他失败、4批量中有失败项、130中断。直接`--output -`输出完整结果。源码入口为`python -m arraylab --headless --sparse ...`。

误差统计和馈线物理尺寸继续暂缓；随机选点是一次可复现的优化起点，不是误差统计功能。
