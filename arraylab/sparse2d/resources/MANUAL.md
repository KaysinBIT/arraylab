# ArrayLab 二维稀疏阵列操作指南

从开始页、左侧“二维稀疏设计”或F8进入。右侧停靠区显示稀疏参数，中间显示方案与结果；切换任务保留输入与已计算结果，不会打开独立稀疏窗口。默认关闭运行日志，可从“视图”打开。

## 左侧导航与历史（0.23.0.dev2起）

展开“二维稀疏设计”后，可直接选择阵列布局、二维方向图、扫描切线、阵元幅相、工况指标、方法比较、稀疏后加权及操作说明。“更多分析”集中放置差分共阵、工况比较、加权前后、量化复核、单元快照和结构化共阵示例。

- **本次综合方案**：当前一次综合及其追加加权得到的各个方法结果。点击左侧方案会展示其阵列布局；中间方案表和小窗口下拉框与左侧保持一致，换方案沿用其最差工况选择规则。
- **历史计算记录**：每次成功综合或成功加权的完整快照，用独立编号区分。点击按需载入该次参数、方案、工况和已存指标；双击或Enter可重新载入保存参数。干净的当前记录不会因双击被重复加载。
- **单元预览（待计算）**：只在预览当前输入单元时出现，不冒充已算结果。选择任何结果图节点后返回已保存的计算快照。

左侧与中间图形下拉、标签页、方案选择双向同步。切换视图不会启动综合或加权；计算期间可以查看原结果，但不能切换方案或历史以覆盖正在运行任务的上下文。计算失败或取消时保留旧结果，不新增成功记录。

稀疏历史独立保存在当前用户本地应用数据目录，通常为`%LOCALAPPDATA%/ArrayLab/history/sparse-history.sqlite3`。主程序启动只读记录摘要，进入稀疏模块时恢复上次选中项；其他完整快照在点选时读取，不把全部历史结果同时载入内存。恢复不重新优化或覆盖已保存指标，仍会进行必要的格式/几何校验和绘图。

每条快照上限256 MiB，总记录没有5条自动裁剪；磁盘占用会随历史增长。损坏档案不重建覆盖，单条结果有摘要校验。保存失败的结果暂留内存，关闭时明确显示未保存数量并提示重试或放弃；“导出当前结果”只能备份当前显示的一份，不代表其他待存快照也已备份。需备份全部自动历史时，可在关闭所有ArrayLab窗口后复制整个档案文件。

历史包含已使用的单元数据快照，查看历史不依赖原CSV仍在原位置；再次计算前仍需确认外部输入文件可用。顶部“保存参数/打开参数”继续处理待计算配置，“打开记录”仍用于直线阵/馈电JSON；稀疏历史通过左侧进入，完整结果包继续使用既有导出格式。

## 操作顺序

1. 在右侧“阵列、单元、工况、高级”设置输入；预设仅载入设置，不自动计算。
2. “开始综合”或F5生成规则抽稀、随机对称、贪心交换、模拟退火、重加权ℓ1等方案；中心禁布、多工况时另有固定支撑调幅对照。
3. 从左侧“本次综合方案”、方案表或小窗口下拉框选择结果，切换当前工况、总场/阵因子/单元视图及理想/量化相位。左侧和中央“图形”都可切换视图；“放大图形”打开单图预览。阵元权重/相位和逐工况指标各有明细页。
4. “稀疏后加权”提供minimax LP、Taylor、Chebyshev、Gaussian、均匀权重；追加新行并保留原行，位置和数量不变。
5. 顶部“导出当前结果”保存完整JSON、逐阵元/逐工况CSV、图片和离线HTML。已有目录不覆盖；新目录在全部成功后才发布。

修改输入后，旧结果继续使用已计算快照；右侧的待计算参数不会篡改旧方案的加权、图表或导出。桌面综合与加权使用独立计算进程，显示当前阶段和已用时间；取消会停止并回收计算进程，不必等当前线性规划完成。关闭主窗口时先取消并回收，再关闭窗口。失败或取消保留旧结果。右侧“恢复已计算参数”可恢复当前结果的输入快照。

0.22.0.dev1在“高级→线性规划”提供自动、原求解器（highs）、内点法（highs-ipm）。自动模式在minimax问题的中心对称候选对数不少于128时使用内点法，较小问题仍用原方法；随后5轮重加权继续使用原求解器。完整约束、采样网格、退火步数不变，成功结果检查全部LP不等式、归一化和非负残差。多重最优解可能改变重加权路径和最终L1布局，不保证副瓣更低；复现旧算法时显式选择“原求解器”。JSON设置使用`config.lp_solver`，旧文件省略时默认`auto`。结果记录实际求解器和各轮残差。

重复显示同一结果的方向图摘要复用已存峰值与副瓣指标，并缓存大圆3 dB宽度和方向性积分。指标缺失或视图不适用时按原密网格计算，未降低精度或抽样。便携包请完整解压并保留同目录`ArrayLab-cli.exe`。

## 主要设置

- 候选网格：Nx、Ny和目标阵元K使用正整数文本输入，不再限制4–20、偶数步进或K≤400，参数保存/载入保持精确整数。K必须不超过候选总数及约束下的可用数量。
- 中心对称：偶数K选取反演位置对；奇数K必须使用奇数×奇数网格，保留一个中心阵元，再选择(K−1)/2对位置。中心禁布会使奇数K不可行；最小间距也会约束中心与其他阵元。奇×奇网格使用偶数K时，中心不参与候选组，参考方案明确标为“不含中心”。L1加权解仍是可变阵元数量的对照，不是固定K方案。
- 中心禁布：无孔、矩形孔或圆孔；尺寸以参考波长λ0计，圆孔使用X字段作为直径。
- 最小间距：二维欧氏中心距，以λ0计；0表示不追加约束。全部生成方案都检查间距和禁布区。
- 多工况：最多25个扫描角与频率组合；同一毫米布局和同一幅度向量参与所有工况。每个频率重新设置理想扫描相位，不是固定馈电网络的扫频模型。
- 单元：理想点源、薄线偶极子、贴片标量近似或标量CSV。导入单元的数据快照随结果保存，后续加权和导出无需重读原文件。
- 相位量化：0为理想，1–12 bit为理想综合后的固定布局复核；不进行量化感知优化。

## 自定义规模与资源

例如21×23、K=101和24×25、K=100都可直接输入。允许单行或单列网格；长度1轴的窗权重为1。正整数输入不等于所有组合都具有可优化的副瓣域：例如默认间距下的1×1孔径，主瓣排除区覆盖整个可见区域，会明确提示无法进行副瓣综合，不生成虚假副瓣指标。

开始计算前，程序按完整候选参考阵、工况数、采样数和并行数估计内存，预算取当前可用物理内存及提交量各一半的较小者；无法读取时使用注明来源的保守后备值。超预算时不启动计算，说明预计占用和预算，保留已有结果及可保存的设置。Windows桌面的后台计算还受相同预算的作业内存上限约束，原生求解器实际占用超额时任务会失败并保留旧结果。此估计不代表运行时间或求解器实际峰值的精确保证。

方向图、距离检查、差分共阵和方向性积分采用分块；共阵保留精确差分计数与排序。没有通过降低采样、删减方法或自动改变K来容纳更大的阵列。大孔径的窄波束/旁瓣可能需要更密的优化和复核采样；结果仍是有限网格估计，不是连续角域保证。平面阵馈电接收仍有其独立的200阵元和40λ孔径限制，本次只开放二维稀疏综合规模。

## 送入平面阵电气设计

选好方案和显示工况后，点击“送入平面阵”。传递全部坐标、相对幅度、所选频率和扫描角，载入到平面阵输入，随后自行点击“生成平面阵设计”。已有电气结果保持不变。

此操作使用理想布局及幅度，创建50 Ω输入/节点/负载的并联初始网络和连续扫描补偿；这些阻抗是可编辑初值，不是稀疏综合得到的阻抗。原相位量化码不迁移，因为原工具量化绝对馈相，而电气页量化网络后的补偿电长度。两者的参考及半步取整规则不同。

仅各向同性点源且不超过200阵元、最大孔径40λ的方案可送入当前平面阵电气模型。幅度必须满足电气模型的正幅度和120 dB动态范围约束。非点源、超限或无效方案明确拒绝，不删阵元、不补零、不替换单元模型。

## 无头入口

`ArrayLab-cli.exe --sparse --help`查看完整控制命令，保留Sparse2D的schema_version=1设置和结果格式。

```
ArrayLab-cli.exe --sparse run --config examples/sparse-basic.json --output results/sparse01 --report
ArrayLab-cli.exe --sparse inspect --input results/sparse01
ArrayLab-cli.exe --sparse planar --input results/sparse01 --index 3 --case-index 0 --output results/handoff01
ArrayLab-cli.exe --planar-config results/handoff01/planar-config.json --output-dir results/feed01 --plot all
```

方案索引为0基；先inspect确认行索引，不要依赖固定方法顺序。`planar`另导出source.json来源记录及毫米坐标CSV。`weight`、`evaluate`和`batch`支持已保存结果加权、重新复核与批量任务。默认仅保存JSON，`--report`增加图表；不导入Qt，不依赖独立Demo目录。

稀疏子命令沿用原控制协议：最终成功或失败JSON写stdout，进度JSONL写stderr；退出码0成功、2输入无效、3目标已存在、1其他失败、4批量中有失败项、130中断。直接`--output -`输出完整结果。源码入口为`python -m arraylab --headless --sparse ...`。

误差统计和馈线物理尺寸继续暂缓；随机选点是一次可复现的优化起点，不是误差统计功能。

## 工作台操作

切到稀疏页时，F5、顶部计算、导出、保存图片、复制图形、F1帮助使用稀疏上下文。返回其他页面后恢复原操作。右侧参数停靠区可像其他ArrayLab面板一样隐藏、浮动和恢复；小窗口自动用方案下拉框给图形留出空间。

顶部“打开参数/保存参数”使用稀疏JSON格式。保存当前待计算输入，打开后不自动计算、不替换旧结果。界面设置不接受带非空weighting自动任务的配置，此类配置请用无头入口执行。导入单元的设置保留CSV路径；完整计算结果才内嵌单元数据快照。
