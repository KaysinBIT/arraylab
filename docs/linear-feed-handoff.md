# 直线阵导入馈电设计与波束指向核对

适用于0.23.0.dev0及后续包含本功能的版本。

## 操作顺序

1. 在“直线阵分析”设置参数，按F5计算。每次成功计算自动加入左侧“历史计算记录”，重启后仍可查看。
2. 选择要继续设计的历史结果。若右侧已有未计算修改，导入时仍以所选结果保存的参数为准。
3. 点击顶部“将该阵列导入馈电设计”。程序载入该结果的频率、阵元数、间距及单位、采样步长、扫描角，进入馈电页。
4. 查看阻抗与拓扑，再按F5生成。导入本身不求解；生成之前原馈电图表仍显示旧设计，并有提示。
5. 在“方向图核对”查看“电气模型输出（最终）”，与原阵列的目标激励核对。

![历史计算记录与顶部导入馈电入口](images/workbench.png)

原直线阵是均匀、理想的各向同性阵列。导入将幅相设置初始化为均匀幅度、按目标指向补偿、连续相位，清除旧自定义幅相、量化、误差、失效和支路附加延迟。有效的阻抗设置与可用拓扑保留；奇数阵元不能使用对称串馈时，明确提示并回退并联。之后可以继续添加自己的电气约束。

外部DAT等曲线不包含完整阵列参数时，按钮不可用，不能反推或猜测其阵列几何。原分析结果、已有馈电记录均保留。

## 本次核算发现的问题

在0.22.1隔离窗口中已复现：所选原阵列结果为20°，输入改成45°但没有再次F5，直接切换到馈电页会按当前45°输入生成。旧馈电的正侧向补偿、不补偿或其他幅相设置也会保留。原图和新馈电因此可能对应不同参数，并非同一个设计快照。

新入口明确传递所选计算快照，并建立与原阵列一致的理想扫描输入。端到端检查中，即使当前输入留着45°及旧馈电扰动，导入20°结果后，三种拓扑最终切面峰都恢复到20°，全切面线性功率最大差约6.66×10⁻¹⁶。

## 相位与场的独立核对

阵列沿x轴，切面角θ从+z朝+x为正。令阵元位置为`x_i=(i−(N−1)/2)d`，`k=2π/λ`，均匀扫描的单位总功率激励为：

```text
w_i = exp(−j k x_i sin θ₀) / sqrt(N)
F(θ) = Σ_i w_i exp(+j k x_i sin θ)
```

在θ=θ₀时，各阵元传播相位与扫描激励相位抵消。独立对照直接使用物理坐标和复数指数，没有调用被核对的阵因子函数。全空间功率另用阵元对之间的`sinc(2(x_i−x_j)/λ)`积分核对。

720组覆盖N=1/5/8/16、三种适用拓扑、±20/30/60°、0.4/0.5/0.8λ、λ/mm输入，以及零/非零支路延迟。连续目标扫描补偿下，馈电场幅度最大差6.11×10⁻¹⁵，等高峰集合角差最大7.54×10⁻¹³°。另有30组完整球面及6组正侧向/端射边界核对。没有发现相位正负号、物理端口顺序或角度定义的公式错误，本次没有修改核心电气计算公式。

## 哪些差异属于设置本身

“网络原始输出（未补偿）”没有施加末端补偿，不应要求与目标角一致。“正侧向补偿”明确以0°为有效目标。相位量化、额外偏置、误差和失效也可能改变输出。

例如8元、0.5λ、请求30°：连续扫描补偿的三种拓扑均为30°；不补偿时，并联输出0°，串馈约27.49272°，对称串馈存在约±18.54649°两个峰。这是指定算例，不是误差统计。

自定义CSV的相位列表示**附加偏置**。不能把已经包含扫描相位的整套激励再次作为附加偏置导入，否则会重复调相；本功能不会这样处理。

存在栅瓣时需比较全部等高峰，单阵元没有唯一峰。线阵的三维场具有绕x轴旋转对称性，二维切面代表角不等于唯一三维波束。零点附近的浮点差异会被dB放大，数值核对采用线性场/功率及峰集合。方向性D不代表包含效率与损耗的增益G。
