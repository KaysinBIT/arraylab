# 三维方向图操作与交互

适用于直线阵分析、直线阵馈电、平面阵馈电和子阵中心优化的三维方向图。

- 左键拖动旋转；右键拖动或滚轮缩放。工具栏保留平移、缩放及Home/后退/前进。
- 拖动或连续滚轮期间显示轻量曲面预览；松开鼠标或滚轮停止约150毫秒后恢复完整显示细节。
- 保存图片、复制所需的完整绘制、Home、窗口尺寸改变或切换页面时恢复完整曲面；保存PNG不使用预览曲面。

预览从已有显示网格选取至多600个面，保留主轴截面及已有最大半径样本，不改变方向图的计算网格、复激励、归一化、峰值、3 dB宽度、方向性和副瓣指标。图下摘要仍来自同一计算快照。停止交互后使用原有完整显示曲面；显示网格仍是有限采样，不能据此保证窄瓣均被解析。

连续鼠标事件只保留最新待绘制视角，绘制期间复用不变的图下文字及色标；切换结果时显式注销旧三维坐标轴的鼠标回调，不等待垃圾回收。图下文字采用等价的换行算法和有界布局缓存，窗口大小、字体或DPI变化会重新排版。

本机200元线阵/馈电的真实Qt手势对照中，原先拖动约7.5–8.5帧/秒，修复后约27–28帧/秒；未复现永久死锁。该结果对应1000×760窗口、当前Windows环境及指定算例，不保证所有机器的帧率。测试范围与独立运行包记录见[验证记录](validation.md)。
