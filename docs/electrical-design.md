# 馈电电气设计（0.7.0）

本阶段完成F02及P04–P07的电气功能。按用户选择，基板、线宽和实际馈线路径尺寸暂缓。所有结果属于中心频点、各向同性点源、同一纯电阻负载的理想模型，不是全波结果或实测硬件性能。

## 工作流程

进入“分析 → 馈电网络／电气设计”（F6）。右侧提供直线阵几何与扫描角；本页的“阻抗与拓扑”“幅相与加权”“误差与失效”分别设置网络、目标激励及输出扰动。点击“生成电气设计”后查看阻抗、逐端口幅相和方向图。

方向图同时显示目标激励、网络未经补偿的输出、电气模型输出。三条曲线共用目标激励的相干幅度和作为0 dB参考，不分别把峰值抬到0 dB，因此可看到失效、幅相误差和量化造成的幅度变化。方向性使用每组复激励的全空间辐射功率积分，不等于增益。目标扫描角再加自定义相位偏置后，实际目标主瓣可能改变，应查看计算结果。

## 相位设计

新建设计默认使用扫描补偿；可选择不补偿或正侧向补偿。原始λ/4功分路径的相位为每段−90°。目标相位为扫描所需的相位加自定义偏置：

\[
\phi_n^*=-360^\circ (x_n/\lambda)\sin\theta_0+\phi_{n,\mathrm{offset}}.
\]

正侧向补偿把θ₀置0。不补偿模式保留原始网络相位，但仍计算目标曲线供比较。对补偿模式，每个端口增加与负载相同特性阻抗的理想无损匹配相移，其电长度为

\[
\ell_n^{\circ}=(\phi_{n,\mathrm{network}}-\phi_n^*)\bmod360^\circ.
\]

端口表给出补偿电长度和对应导波波长比例0≤l/λg<1。由于该段与负载匹配，它不改变功分树在设计频点看到的负载。这里没有给出毫米长度，也不声称这是宽带真时延系统。SVG仅画功分主干，端口补偿参数在表格/CSV中。

## 幅度加权及功率分配

支持均匀、Chebyshev、Taylor和自定义分布。生成的目标幅度先以最大值归一化，然后按幅度平方分配总功率：Pₙ=aₙ²/Σa²；进入方向图的名义功率波幅度为√Pₙ。网络各支路按下游功率和重新综合阻抗，不沿用均匀阵的端口数量比例。

- Chebyshev：旁瓣参数45–120 dB；采用对称权重。
- Taylor：旁瓣参数20–100 dB，nbar为2–20且不大于阵元数（单阵元退化为1）。
- 自定义：每个目标幅度须为正，归一化后最小值不得低于10⁻⁶，即最大120 dB幅度动态范围。零目标功率将需要断开或重新设计支路，本版不以无限阻抗代替。
- “1分2＋对称串馈”要求目标幅度按端口编号镜像对称，保持首级等分及两臂阻抗对称；扫描相位无需镜像相等。

加权参数不保证在任意阵元间距、扫描角、元素方向图或实际耦合条件下达到同样的旁瓣指标。实现使用[SciPy Chebyshev窗口](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.windows.chebwin.html)和[Taylor窗口](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.windows.taylor.html)，测试另以Chebyshev多项式和Taylor乘积公式核对。

## 自定义激励文件

CSV严格使用下列三列表头，阵元编号从1连续排列，必须恰好N行：

```csv
element,amplitude,phase_deg
1,1,0
2,2,10
3,2,10
4,1,0
```

amplitude是线性相对幅度，不是dB；phase_deg是加到基准扫描相位上的偏置，单位为度。缺失、多余、重复/乱序编号、非有限值、额外列和错误表头都拒绝；失败不替换已有输入。导入后可先“预览输入”，再生成设计。

`feed-target-excitation.csv`使用同样格式，输出归一化幅度及原相位偏置，可以往返导入。原始幅度的共同缩放不改变名义总功率归一化后的结果。`feed-output-excitation.csv`含实际输出复数分量，属于结果，不能直接当成上述输入CSV。

## 误差、失效与量化

移相位数0表示连续相移，1–12位将补偿电长度取最近的2ᴮ个相位状态；半步按较大的电长度状态取整，360°回绕至0°。不补偿模式不接受非零量化位数。

幅度误差是每阵元独立的零均值高斯dB误差（σ为0–10 dB），相位误差是独立零均值高斯角度误差（σ为0–180°）。明确记录0至2³²−1的随机种子；同一软件及依赖版本、同一输入可复现。显示的是**一次随机实现**，没有蒙特卡洛平均、置信区间或误差旁瓣统计承诺。

失效按“仍匹配吸收功率、辐射激励置零”处理，不计算开路/短路反射及网络功率重分配。失效端口的输出相位为JSON null、CSV空白；全失效时方向性和主瓣不定义。输出功率比只是该激励扰动模型的幅度平方比，可能因正幅度误差大于1，不是被动网络效率。报告另列失效端口所占的名义功率比例。

## 指标及验证边界

复激励场采用逐阵元复数求和；全空间功率由各阵元间距对应的sinc核计算。直线阵峰值在空间频率上搜索/细化，与显示步长无关；正幅度线性相位可使用相干和上界。极近间距的抵消情形使用积分回退，仍不保证任意病态超指向激励的精度。多等高主瓣、全向、全零及边界不完整时不报告唯一宽度。

独立验证包括λ/4线ABCD电路、匹配端口相移、数值积分、窗口闭式公式，以及均匀/无误差退化、端射、栅瓣和全失效案例。

## 设计记录和导出

直线阵馈电页保留最近5项设计，可改标签、选定记录和比较其模型输出。选择记录不覆盖当前输入；生成、表格、指标与导出均保持快照一致。“保存设置”保存当前输入；“导出结果”保存所选记录；“导出比较”包含每项标签、完整输入和计算数据。历史间各曲线使用自身目标相干和参考，比较文件保留归一化定义。比较记录当前为导出格式，不作为可重新导入的完整工程文件。

新版馈电配置为`arraylab.feed_impedance`、schema_version=2。旧版版本1文件继续可读，按均匀幅度、未补偿、无误差解释；不会自动改变旧设计。新建GUI和CLI默认均为扫描补偿。

无头例子：

```powershell
python -m arraylab --headless --elements 16 --scan-deg 30 --feed-network symmetric_series --feed-phase scan --feed-weighting taylor --feed-sidelobe-db 30 --output-dir results/taylor --plot both
python -m arraylab --headless --feed-config examples/feed-electrical.json --feed-phase-bits 3 --feed-phase-error-deg 5 --feed-amplitude-error-db 0.5 --feed-failed-ports 3 --feed-seed 42 --output-dir results/errors --plot both
```
