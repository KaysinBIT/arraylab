# 计算记录与文件选择

适用于ArrayLab 0.23.0.dev0。直线阵每次成功F5都会自动追加到“历史计算记录”，重启后恢复已有结果和选中项，不重新计算。顶部“保存记录”可另外导出记录文件；“保存参数”只保存输入，需要重新计算。直线阵馈电仍通过“保存记录”保存其设计列表。

## 三种保存的区别

| 操作 | 文件包含什么 | 重新打开后会怎样 |
| --- | --- | --- |
| 保存参数，Ctrl+Shift+S | 当前任务的有效输入，包括尚未运行的修改 | 用“打开参数”或Ctrl+Shift+O载入，再按F5计算 |
| 保存记录，Ctrl+S | 直线阵或直线阵馈电的完整已有结果、各条标签及保存时的选中项 | 用“打开记录”或Ctrl+O恢复；不重新运行计算 |
| 导出当前结果，Ctrl+E | 当前选中结果的数据、表格或报告，类型随任务变化 | 馈电导出的完整feed-network.json可恢复为一条设计；其他导出用于外部查看和处理，不等于恢复全部计算记录 |

例如：你已经计算20°，随后把输入改成30°但没有运行。此时“保存参数”保存30°输入，“保存记录”和“导出当前结果”仍保存20°计算结果。保存记录不会顺带执行尚未运行的计算。

## 保存并恢复一组结果

1. 在“直线阵分析”或“直线阵馈电”完成计算。直线阵每次成功F5都保留，“叠加比较（最多5条）”只决定图形显示所选结果及最近几条，不会删除其他历史；馈电会保留最近5项设计。
2. 用“结果”或“设计记录”下拉框选中希望下次首先看到的一条。馈电记录可用“改名”设置容易辨认的标签。
3. 点击顶部“保存记录”，例如保存为`linear-history.arraylab.json`或`feed-history.arraylab.json`。
4. 下次启动后，点击开始页“打开以前保存的计算记录…”，或顶部“打开记录”。程序自动进入文件对应的任务。
5. 查看恢复后的所选结果，再切换其他记录比较；需要基于参数做新计算时，修改输入并按F5。

打开直线阵记录文件会追加到当前历史并选中该文件原选中项，已有F5结果保留；重复打开同一文件会再次追加。打开馈电记录仍替换其当前设计列表。每个记录文件只保存一种任务，直线阵与直线阵馈电需要分别保存。

## 直线阵自动档案

正常启动后，直线阵结果保存在当前Windows用户的本地应用数据目录，路径通常为`%LOCALAPPDATA%/ArrayLab/history/linear-history.sqlite3`；导航“历史计算记录”的提示会显示实际位置。档案位于程序目录之外，升级或重新解压运行包不会覆盖它。从本版本开始自动留存，旧版未保存的会话结果不能据此追回；旧记录文件可以通过“打开记录”追加。

每条成功计算结果独立提交，关闭或重启恢复已存快照，不重新求解。删除只移除明确选择的记录；删除后序号继续增长。多个窗口各自追加，不用一份旧列表覆盖另一个窗口的新结果。打开文件追加的记录也会自动留存。

磁盘满、档案被占用或格式损坏时会显示错误；新结果仍保留在当前会话，旧档案不会被重建覆盖。若退出时仍有未自动保存的结果，程序会提醒返回备份或明确放弃。可使用“保存记录”导出JSON；大量历史也可在关闭所有ArrayLab窗口后备份整个自动档案文件。

## 恢复范围

| 记录类型 | 会恢复的内容 |
| --- | --- |
| 直线阵计算 | 曲线、相位、阵元位置与激励相位、已算指标、提示信息、标签和选中项 |
| 直线阵外部曲线 | 导入的角度、幅度、可选相位及标签；仍保留为外部数据 |
| 直线阵馈电 | 几何及馈电设置、节点与支路、端口幅相、目标/未经补偿/输出方向图、指标、说明、标签和选中项 |

如果保存时选中的是本软件计算的直线阵结果，打开后右侧输入会恢复为这条结果的参数；馈电记录同样恢复所选设计的几何及馈电设置。如果选中的是外部曲线，它不含本软件的阵列参数，当前输入会保留，并显示相应提示。

恢复读取保存时的科学结果，不重新搜索峰值、不重新综合馈电、不重新抽取随机误差。已保存的曲线和指标保持原值。

直线阵馈电页中间的“设计记录”下拉框会同时恢复所选设计的阵元数量、间距、扫描角、馈电阻抗、幅相设置、支路电长度及已有结果。只有一条记录或已经选中该条时，再次点选也能恢复它；不必先切换到其他条目。未运行的输入修改如需保留，应先点“保存参数”。空列表会显示“暂无设计记录，请先生成或打开记录”。生成设计或从顶部打开记录后，下拉框会启用。

直线阵分析的“结果”切换仍主要用于查看曲线；右侧输入与所选结果不同时会提示结果所属状态。修改参数后，要生成新结果仍需明确运行计算。

上述JSON记录文件不包含未计算输入、窗口布局、全部任务状态或多角度扫描结果。平面阵和子阵中心优化仍使用参数保存及结果导出。0.23.0.dev2起，二维稀疏另有自动历史档案，保存每次成功综合/加权的完整快照，由左侧“历史计算记录”打开；它不混入上述直线阵/馈电JSON格式，详见[二维稀疏指南](sparse-arrays.md)。

## 旧馈电比较文件

0.22.1.dev0起，也可直接用“打开记录”选择馈电导出目录内的`feed-network.json`。它恢复为一条设计，保留保存时的支路电长度、端口相位、曲线和指标，不重新计算。0.21和0.22生成的完整馈电电气报告均支持。若需要保存多条设计及所选项，仍用“保存记录”。

`feed-config.json`只保存参数，不含已计算结果，应使用“打开参数”，随后运行设计。误选参数文件时会提示正确入口，当前结果保持不变。

此前通过馈电页“导出比较”生成的`feed-comparison.json`可以用“打开记录”载入。支持`arraylab.feed_comparison`第1版封装及其中完整的馈电电气报告；0.11、0.12的第2版馈电结果报告在支持范围内。旧格式没有保存选中项，打开时默认选择最后一条。

旧报告缺少指向摘要时，程序根据已保存的峰值和目标参数补齐摘要；不会重新计算方向图或改写原文件。只含输入的馈电参数文件、缺少完整电气结果的阻抗报告，不能作为完整计算记录打开。

## 数量、文件大小和失败处理

手动JSON文件中，直线阵允许1–100000条记录，馈电仍为1–5条；整个文件最大64 MiB，单个数组最多100000点。自动档案按单条快照校验和事务写入，总记录不受“5条”或单个JSON文件64 MiB限制，不自动裁掉旧结果；实际容量受磁盘和可用内存影响。文件使用版本化JSON，不使用可执行脚本或pickle。加载会先检查全部记录，未知版本、重复字段、非有限数值、缺失字段和不匹配的数组长度会被拒绝。

保存前先完成内容校验，再通过同目录临时文件替换目标文件。校验或替换失败时原文件保留。保存到已有文件时，文件对话框会确认覆盖。

如需识别文件类型，新格式顶层为`format: arraylab.calculation_history`、`schema_version: 1`，`kind`取`linear`或`feed`；`records`保存完整快照，`selected`从0开始标记所选记录。正常使用直接通过界面保存和打开即可。

## 多角度评估窗口的保留方式

对同一项已生成设计，关闭“多角度评估”窗口后再次打开，会保留本次会话的扫描设置和结果。切换或重新生成设计后，会以相应设计建立扫描。这项会话内保留不等于把扫描结果写入上述计算记录文件；退出主程序前，应按需保存扫描设置并导出扫描结果。详见[扫描评估指南](scan-study.md)。

## MIMO完整记录（0.24.0.dev0起）

MIMO页的“保存记录”保存当前成功结果、输入快照和所选视图，格式为`arraylab.mimo.record`；“保存参数”使用独立的`arraylab.mimo`格式。打开完整记录会自动进入MIMO任务，恢复Tx/Rx、通道映射、虚拟几何、已存场/指标和视图，不重新计算。加载前检查摘要、格式、采样与几何映射；失败保留当前输入和结果。

MIMO首版没有自动追加历史数据库，关闭前需要手动保存记录或导出完整结果；不与直线阵/馈电的多记录文件混合。导出的`mimo-record.json`可直接通过“打开记录”恢复。原来的自动直线阵/二维稀疏档案保持独立。
