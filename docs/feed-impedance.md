# 馈电网络阻抗设计

0.5.0新增功能。根据用户要求，当前阶段只进行并联/串行馈电的**阻抗值设计**。这项新增研制功能不等同于原说明书已确认的馈电网络综合能力；不把说明书中的单条传输线或匹配计算扩大解释为完整馈电网络设计。

## 操作与输入

在顶部“分析 → 馈电网络／阻抗设计”、左侧“馈电网络 · 阻抗设计”或按F6进入页面。选择拓扑，设置阻抗后点击“生成阻抗”。阵元数与设计频率取右侧当前输入。默认8阵元、3 GHz，以及输入、节点和阵元负载均50 Ω；这些仅为可修改初值。

| 输入 | 含义 |
| --- | --- |
| 阵元数N | 1–200，与当前阵列参数一致 |
| 输入阻抗 | 输入参考面期望看到的纯电阻R₀ |
| 节点阻抗 | 每个内部下游分支节点的等效输入纯电阻Rⱼ；不是每条传输线的特性阻抗 |
| 阵元负载 | 所有输出端口使用相同的纯电阻Rᴸ，不接受复阻抗 |
| 提示下限/上限 | 用户自定的变换线阻抗筛查范围，默认20–120 Ω；并非工艺可实现范围的保证 |

5项阻抗输入均限定1–1000 Ω，下限须小于上限；计算得到的变换线阻抗允许超出该输入范围，并以实际值显示。上述范围是软件输入约束，不是器件功率、精度或制造承诺。

当前目标为等功率分配。在相同实负载下，也对应相同端口电压幅度。阵元间距、扫描角和方向图采样步长不参与本阶段阻抗计算；保存它们用于保留阵列上下文。设计频率规定每段λ/4线的90°电长度，未设置介质时不输出毫米长度。

## 拓扑定义

**并联树形馈电：** 按连续端口编号递归二分，左右端口数分别为⌊m/2⌋与剩余数量。二的整数次幂端口数形成完整二叉树；其他数量允许不等功分及不同路径级数，不用虚拟负载凑数。

**串行逐级抽头馈电：** 每个T型节点抽取一个阵元所需功率，其余功率继续送往下游。抽头和续传支路均由一段λ/4变换线实现；最后一级为两路分配，末端负载就是最后一个阵元，无额外终端电阻。它不是所有形式的串馈贴片阵或行波辐射线的通用模型。

N=1时为一段输入至负载的λ/4匹配线，没有功分节点。N>1时两种拓扑均有N−1个T型节点和2(N−1)条变换线。

## 阻抗计算依据

对节点等效输入阻抗Rₚ、某支路的局部功率比例f及其下游等效实负载R𝚌，同一并联节点的支路电压相同，因此：

\[
R_{\mathrm{branch}} = R_p/f,\qquad
Z_t = \sqrt{R_{\mathrm{branch}}R_c}.
\]

两支路满足f₁+f₂=1，因而支路输入阻抗并联为Rₚ。四分之一波长线在中心频点满足Zᵢₙ=Zₜ²/R𝚌。该基本变换关系见[Ansys的λ/4变换器说明](https://optics.ansys.com/hc/en-us/articles/360042041094-Quarter-wave-impedance-transformer)；本项目据此按树形/逐级抽头结构逐段综合。

并联中f为该支路下游端口数除以当前节点下游端口总数。串行中若剩余m个端口，抽头f=1/m，续传f=(m−1)/m。

8端口、输入/节点/负载均50 Ω时：

| 拓扑与支路 | 局部分配比 | 支路输入阻抗 | λ/4变换线阻抗 |
| --- | --- | --- | --- |
| 并联，每级二等分支路 | 1/2 | 100 Ω | 70.710678 Ω |
| 串行，首级抽头 | 1/8 | 400 Ω | 141.421356 Ω |
| 串行，首级续传 | 7/8 | 57.142857 Ω | 53.452248 Ω |
| 串行，末级两支路 | 1/2 | 100 Ω | 70.710678 Ω |

默认20–120 Ω提示范围下，8路串行有3条抽头变换线超限。提示只指出阻抗较高，不据此断言不能制造。并联5路时，首级比例为2/5与3/5，对应79.056942 Ω与64.549722 Ω。

## 相位及物理边界

每段理想λ/4线对实际端口电压增加−90°相移。端口列表给出从输入起的线段数、累计未补偿相位和总功率占比。二的整数次幂并联树中心频点等相；非等深树和通常的串行网络可能不等相。即使等相，也尚未加入扫描所需馈相。

因此馈电结果保持独立，不改变现有理想均匀阵方向图，也不将其标为该馈电网络的实际辐射结果。

本模型假定节点理想、线段无损、负载固定为纯电阻。它不是带隔离电阻的Wilkinson功分器，不提供输出隔离保证；未计算实际S参数、带宽、互耦、损耗、功率容量、基板、线宽、弯折/连接不连续、物理走线长度或制造公差。连接SVG中的几何距离不参与计算。以上环节将在阻抗方案选定后逐步设计。

## 保存、导出与无头使用

“保存设置”保存当前输入；“打开设置”校验后恢复阵列和馈电设置，提示重新生成。“导出结果”保存当前表格对应的设计快照，未计算的修改不会串入已有结果。导出选择父目录后会自动新建带时间戳的子目录，不覆盖已有目录。

- `feed-config.json`：输入配置，格式`arraylab.feed_impedance`、版本1，完整保存6项阵列参数及6项馈电设置。
- `feed-network.json`：完整计算报告，含节点、变换线、端口、输入快照、指标及限制。
- `feed-sections.csv`：各线段阻抗、功率比例、起止节点和超限标记。
- `feed-ports.csv`：输出负载、总功率比例、路径级数及未补偿相位。
- `feed-network.svg`：可缩放的连接示意，支持两种拓扑，标注线段编号和阻抗。

```powershell
python -m arraylab --headless --elements 8 --feed-network corporate --output-dir results/feed-parallel
python -m arraylab --headless --elements 8 --feed-network series --feed-load-ohm 50 --output-dir results/feed-series
python -m arraylab --headless --feed-config examples/feed-series.json --output-dir results/feed-reloaded
```

CLI同时输出原有理想阵列分析和独立的`feed_network`报告；两者物理含义不同。可用`--feed-input-ohm`、`--feed-junction-ohm`、`--feed-load-ohm`、`--feed-min-line-ohm`、`--feed-max-line-ohm`覆盖输入。只提供阻抗选项而未选`--feed-network`或`--feed-config`时拒绝运行，避免参数被忽略。

`--feed-config`与`--config`互斥；前者已经包含阵列参数。显式命令行选项覆盖有效文件值，不修改文件。未知版本、缺失/未知/重复字段和非法类型均拒绝；计算报告不能冒充输入配置。现有6参数分析方案保持原格式，不包含馈电设置。

## 后续顺序

先根据实际输入阻抗、阵元复阻抗及工艺范围选定阻抗方案；再处理端口相位均衡/扫描馈相、介质与线宽尺寸、传输线和节点损耗，最后进行网络与天线联合验证。串行主干长度与阵元间距的布线关系需要在物理阶段另行确定。
