# 二维稀疏功能合并记录

来源为用户工作区的MIT许可Sparse2D 1.3.0。原`sparse2d_demo`目录保留；本次移入`arraylab.sparse2d`命名空间，运行包和源码安装均不依赖原目录。不包含独立MBFN MIMO项目、训练数据、运行日志、历史生成结果或原EXE。

| 原能力 | ArrayLab接入方式 |
| --- | --- |
| 规则/随机中心对称选点、贪心交换、模拟退火、重加权ℓ1与取整参考 | F8原生二维稀疏页；`--sparse run` |
| 中心矩形/圆形禁布及最小二维欧氏间距 | 原参数、可行性判断和结果复核均保留 |
| 固定支撑LP、Taylor/Chebyshev/Gaussian/均匀加权 | 原稀疏后加权页；`--sparse weight` |
| 多扫描角/多频率共同布局与共同幅度 | 原工况设置、工况切换和逐工况导出 |
| 理想点源、偶极子、贴片近似、导入标量单元 | 原单元页、内嵌结果快照、模板资源 |
| 相位量化复核与代码表 | 原量化页、理想/实际方向图及`evaluate --phase-bits` |
| 图形放大、方向图、共阵、完整报告 | 主工作台图形页及单图预览；离线HTML/CSV/JSON/PNG，原子发布新目录 |
| JSON API、批处理、保存结果复核 | `--sparse defaults/validate/run/inspect/weight/evaluate/batch` |
| 新增平面阵联动 | 选中行和工况送入电气页；`--sparse planar`另可导出来源记录和可复算设置 |

0.9.0迁移时，原六个数值模块core、constraints、scenarios、elements、phase_quantization、weighting通过语法树对照确认：除包内相对导入外计算代码保持一致。原数学、单元和相位测试迁入当前测试目录，另增加统一CLI及坐标/幅度联动检查。

集成改变包括：内部相对导入、主工作台按钮/导航/F8入口、独立工作窗口生命周期、避免修改全局绘图样式、统一可写数据目录、帮助与模板打包、结果版本标识、完整报告原子导出和受检查的电气联动。数值模块没有为合并重新编写优化算法。

稀疏模块的PSL、方向余弦HPBW、标量单元总场与电气页的全空间方向性保持各自定义。理想布局/幅度可传递，但原绝对相位量化码不等同于新馈电网络的端口补偿量化码；因此联动从连续相移和50 Ω并联初值开始。非点源与电气页规模/孔径/动态范围不兼容时拒绝传递，不静默降级。

稀疏多频综合仍为逐频重设理想扫描相位，不代表固定馈电网络频率响应已经实现。误差统计和馈线物理尺寸继续暂缓；原独立工具的多种子统计脚本未加入统一入口。

## 0.10.0原生界面修正

按用户要求，删除原Sparse2D的gui和detail_view界面实现，改用ArrayLab原生QWidget页面。左侧导航、中央文档页、右侧参数停靠区、顶部计算/导出和底部消息共用主工作台；不继承或装载原独立窗口。图形复用数值绘图函数，单图放大为用户主动打开的预览对话框。新增阶段间取消及紧凑方案选择；算法与无头协议保持不变。

## 0.12.0有界并行复核

core增加按方案并行的复核调度，phase_quantization增加工况间取消检查，weighting使用同一受控复核入口。偶极子归一化缓存先在协调线程填充，工作线程只读几何、网格和单元数据，各自生成结果。贪心、退火、LP及其随机数顺序保持。单项加权仅有一个布局，继续串行。运行资源不写入科学配置，结果附加execution说明实际使用路数；旧结果仍可读取。[范围与控制](multicore.md)。
