# 方向图、三维显示与主要指标

方向图下方的摘要对应当前选中的计算记录、激励来源和工况。摘要是图像的一部分，保存或复制当前图形以及无头导出 PNG 时会一并保留；窄窗口会自动折行。尚未运行的输入修改不会改变旧结果的图形和指标。

## 查看线阵三维方向图

在“直线阵分析”完成计算后，将显示方式从“直角坐标”或“极坐标”切换到“三维方向图”。三维图只显示当前选中记录，二维图仍可叠加比较多条记录。

在“直线阵馈电”的方向图页，先选择显示方式，再通过“指标／三维来源”选择：

- **目标激励**：期望阵元幅相产生的场。
- **网络原始输出**：补偿之前的网络输出场。
- **电气模型输出**：包含当前补偿、量化、已设置单次误差及失效端口的实际模型输出。

这三个来源均使用当前设计记录保存的激励。切换视图不重新综合馈电，也不重新抽取随机误差。

三维图支持鼠标旋转及工具栏缩放。阵列沿 x 轴，球面角 θ 从 +z 轴量起，范围 0–180°；φ 从 +x 朝 +y，显示范围 −180–180°。计算采用方向余弦 `u = sin(θ) cos(φ)`。原二维切面使用从 +z 朝 +x 为正的有符号角 −90–90°，与球面 θ 的定义有所不同。

三维半径表示相对场幅度，颜色表示同一参考下的 dB。均匀线阵按理论峰值归一化；馈电方向图沿用目标相干幅度和作为参考，因此实际输出的峰值不一定为 0 dB。图中 dB 颜色不是 dBi 增益。

当前线阵模型为各向同性阵元的阵因子，绕 x 轴旋转对称。二维切面中的一个峰，在三维中可能对应一圈等响应方向。三维图及局部宽度不能证明存在唯一空间波束。

## 图下主要指标

| 指标 | 含义与边界 |
| --- | --- |
| 切面主瓣／代表峰 | 线阵显示二维切面峰值角；平面阵显示上半球代表峰 θ、φ。极点的 φ 无唯一值。 |
| 切面 3 dB 宽度 | 包围所选主瓣的两个半功率交点之间的角宽，单位 °。使用相对该主瓣峰值的半功率阈值。 |
| 正交切面宽度 | 通过所选空间方向的子午、横向两条正交大圆切面的局部半功率宽度，单位 °。 |
| 指向偏差 | 线阵为切面峰值减有效目标角的有符号偏差；平面阵和稀疏阵为代表方向与目标之间的球面夹角。 |
| 峰值方向性 D | 场峰值相对于全空间平均辐射强度的比值，以 dBi 表示。必须具有足够的完整空间模型。 |
| 增益 G | 方向性还需结合辐射效率；当前没有效率模型，显示“未计算（缺效率）”，不将 D 改名为 G。 |
| PSL | 主瓣排除区域以外的最大相对电平。切面 PSL 和空间采样 PSL 的区域定义不同，不能直接当成同一指标。 |

半功率阈值是相对峰值下降 `10 log10(0.5) ≈ −3.0103 dB`，通常称为 3 dB。比如实际输出主瓣为 −2 dB，半功率交点应取约 −5.0103 dB，而不是图上的固定 −3 dB。

已有均匀线阵与复激励线阵的主瓣和半功率宽度继续采用原有独立于显示采样的计算结果。外部二维曲线及新增通用切面测量采用采样和插值，并明确属于估计值。无唯一主瓣、全向或缺少完整交点时，不强行报告单一宽度。

### 两个三维局部宽度

“子午”切面的切向对应增加 θ 的方向，“横向”切面的切向与之正交，两者都经过所选峰。它们是球面大圆切面，不是固定 θ 的方位小圆；当前没有极化定义，因此不称为 E 面和 H 面。

极点处需要一个参考 φ 来确定两条切面的方向。正侧向线阵的横向切面可能处处等高，因而没有有限半功率宽度；扫描后的线阵在这两条大圆上可能均有有限宽度，但仍保留轴对称空间峰。字段缺失表示没有足够边界或不适用，不表示宽度为零。

### 切面 PSL 与空间 PSL

**切面 PSL** 用当前主瓣左右最近的采样极小值限定主瓣区域，再寻找区域外的最高电平，相对于所选峰值报告。若无法找到两侧极小值，不猜测排除区。其他等高峰或栅瓣不会因“也是主瓣”而全部被排除；可得到接近 0 dB 的 PSL。切面结果受角步长影响，不是连续角域峰值保证。

**二维稀疏的空间 PSL** 在可见 u/v 圆盘内计算，使用参考完整阵列决定的固定主瓣矩形：相对目标方向的半宽为 `1/(Nx·d)`、`1/(Ny·d)`，其中 `d` 使用当前工况的波长尺度。图下摘要采用与复核一致的加密、错位及边界采样，按框内代表主峰归一化。原工况表中以目标响应为参考的数值可能与这个主峰参考不同，特别是总场或量化相位使峰值偏移时。

**子阵中心优化的空间 PSL** 使用用户指定的 u/v 排除半宽，并在加密、错位采样上复核。该区域可能保留主瓣裙边，也可能排除过宽；需要结合方向图检查。它不是自动查找首零点的副瓣指标。扩大排除区不应被解释为改善实际辐射性能。

空间 PSL、峰值位置和采用采样峰值的方向性均保留数值估计的性质。增加网格密度有助于复核，但不能保证找到连续域最坏副瓣或全局最优布局。

## 数据不足时的显示

扫描评估窗口的“选定扫描点方向图”也附带切面HPBW与PSL。该报告原有方向性是**目标方向D**，图下保留这一名称，不将它冒充峰值D；扫描总览图仍用于比较不同工况。

- **导入的二维曲线**：可以估计该切面的峰值、半功率宽度及满足边界条件时的 PSL；缺少阵列模型与完整激励，不能恢复三维方向图，也不能从单一切面推断全空间方向性。
- **稀疏阵非各向同性单元总场**：当前单元响应接口限定前半球，不用镜像或补零假设制造背面数据。总场方向性显示不可用；局部宽度搜索到前半球边界即停止。即使导入文件含更多角度，也不自动扩大该接口的空间定义。
- **稀疏阵“阵因子”视图**：采用完整的各向同性点阵模型，可以计算完整空间积分，但峰值来自采样，仍标为估计。
- **全零输出**：方向性、主瓣及宽度不定义。
- **增益与实现增益**：当前没有辐射效率、损耗和失配功率参考面的完整输入，因此不报告真实增益或实现增益。归一化方向图的 0 dB 不能充当这些数值。

## 历史记录与导出

直线阵与直线阵馈电仍使用原计算记录格式。打开记录后，保存的曲线、激励及已有计算指标保持不变；新三维采样、切面 PSL 和图下摘要由这份快照派生。不会使用右侧尚未运行的输入，也不会重新执行随机误差或馈电综合。

“保存图片／复制图形”包含当前图形和图下摘要。“导出所选曲线”仍是二维曲线交换，不等同于导出完整球面数据。需要球面数据时可使用无头输出目录；馈电结果目录也包含各来源的球面 CSV。平面阵、二维稀疏与子阵中心优化保持各自参数保存和结果导出方式，不因此获得完整多次历史记录恢复。

## 无头入口

以下命令适用于源码环境；输出目录必须尚不存在。使用打包程序时，可将 `python -m arraylab --headless` 替换为 `ArrayLab-cli.exe`。

```text
python -m arraylab --headless --elements 8 --scan-deg 20 --output-dir results/linear3d --plot all
python -m arraylab --headless --elements 8 --scan-deg 20 --feed-network corporate --feed-phase scan --output-dir results/feed3d --plot all
python -m arraylab --headless --planar-config examples/planar-rectangular.json --output-dir results/planar3d --plot all
python -m arraylab --headless --sparse run --config examples/sparse-basic.json --output results/sparse-metrics --report
python -m arraylab --headless subarray --config examples/subarray.json --output results/subarray-metrics --plot all
```

线阵的 `--plot 3d` 只生成三维 PNG；`--plot all` 生成直角、极坐标及三维 PNG；原来的 `--plot both` 仍仅表示两种二维图。

| 输出 | 内容 |
| --- | --- |
| `3d.png` | 均匀线阵三维阵因子及图下摘要 |
| `feed-3d.png` | 馈电电气模型输出的三维场及图下摘要 |
| `sphere-pattern.csv` | 均匀线阵的球面 θ、φ、相对场幅 dB 和场相位 |
| `feed-target-sphere.csv` | 馈电目标激励的球面数据 |
| `feed-uncompensated-sphere.csv` | 网络补偿之前的球面数据 |
| `feed-output-sphere.csv` | 电气模型输出的球面数据 |

线阵球面 CSV 默认按 2° 采样。馈电与均匀线阵的球面数据在指定输出目录时生成，不要求同时绘图。显示网格和球面 CSV 可能漏掉窄瓣，不能替代精确线阵指标或更细采样的复核。无头图片使用英文标签，避免依赖中文字体；不导入 Qt。
