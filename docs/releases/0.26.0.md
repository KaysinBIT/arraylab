# ArrayLab v0.26.0

0.26.0 将相控阵雷达设计、雷达方程验证、脉冲雷达设计及FMCW三维场景纳入正式发行。提供Windows x64桌面程序与独立无头命令行，无需另装Python、浏览器、Node.js或启动原项目服务。

## 雷达设计能力

- **相控阵设计：同步ArrayStudio 1.2.1。** 支持规则及自定义阵列、固定移相与真时延、扫描性能评估、一维与二维稀疏综合。布局、切面、u-v图、实际馈相和逐工况指标跟随所选工况显示，可将该工况送入平面馈电设计继续核对。
- **雷达方程验证：同步EquationLab 1.0。** 提供系统预算与反算、回波仿真、固定CUT的SNR对照、独立H0门限校准、Pd/Pfa、距离网格统计和经验ROC。参考预算与接收处理链保持独立，校准可用不等于独立统计验收已经通过。
- **脉冲雷达设计：同步PulseLab 1.0.1。** 支持矩形、LFM、二相码、步进频，均匀/交错PRI及多PRF，相控、TDM和CDM。可查看回波与脉压、距离–速度、检测/测角和模糊候选，使用地形场景、独立统计与有界反向设计。

[组件选择与操作顺序](https://github.com/KaysinBIT/arraylab/blob/v0.26.0/docs/radar-components.md)

## 三维场景与操作界面

- 原“雷达波形设计”统一更名为 **FMCW雷达波形设计**，开始页、左侧任务树、菜单和工具栏保持一致。
- 脉冲雷达保留原PulseLab的深色透视场景、平台和天线实体、透明波束、目标、轨迹及地形。支持旋转、平移、缩放、播放、视角复位和PNG导出。
- FMCW与脉冲共用同一离线场景组件。FMCW按已计算A/B快照显示单目标与天线指向，切换组别保留目标和视角；近距离目标自动取景。没有完整波束宽度时只显示已知指向箭头。
- FMCW显示角度和运动方向是显式预览设置，不回写波形输入或改变计算结果。三维场景隐藏时暂停播放和渲染。

[FMCW三维操作与模型边界](https://github.com/KaysinBIT/arraylab/blob/v0.26.0/docs/radar-waveforms.md)

## 结果复用、记录与资源控制

- 从已计算直线阵、二维稀疏、MIMO或相控阵快照向雷达方程/脉冲模块导入Tx或Rx几何；明确转换单位和坐标，不推定实际天线增益。波形导入读取当前已计算的FMCW A/B组。
- 三组件支持完整数值记录、异步读取和原子导出。导出目录共用一份数组文件，并通过摘要核对记录与数值；多工况馈相表和场景图对应当前选择。
- 视角、时间与FMCW显示设置可随记录恢复。取消、失败或坏文件不会用未完成结果覆盖上次成功快照。
- 复用参数表单、文件接口、后台进程和绘图组件。新增雷达计算采用受管进程与内存预算，保留单核和有界多核；避免多个耗时任务同时启动。运行目录的Python模块集中在归档内，完整源码另行提供。

## 兼容与适用范围

- 既有模块的命令、配置与历史路径保持；FMCW仍使用`waveform`命令。新三组件有独立参数和记录入口，不启动或修改原项目工程。
- 新三组件完整记录为`.npz`；导出的`arraylab-record.json`与`arrays.npz`应一起保留。FMCW包含场景状态时使用记录schema2，并继续读取原schema1；数值报告schema2不变。旧程序不保证读取新增组件或场景记录。
- 导入基于成功计算快照，不采用尚未计算的输入。非各向同性单元不能直接迁移；Pulse 1.0.1不接受非等幅通道；交替A/B不能当作独立均匀波形组导入方程模块。改变相关输入后需重新校准和验证。
- 数字波束、方向性及通道数量不等于真实硬件增益、RF链数或实测分辨率。FMCW默认网格是局部坐标参考，不表示实测地形；透明锥体和指向箭头不代表真实增益等值面或探测范围。脉冲模块导入的DEM按其坐标与高程基准使用，未知位置保留未知。
- 稀疏综合是有限搜索与采样复核；小样本统计不能证明极低虚警率。物理馈线尺寸、天线误差统计专题及阵元互耦/极化的全波建模继续暂缓。

## 发布验证

本次正式整理沿用已验证的0.26.0.dev2业务实现。正式包15项桌面专项检查及6项无头版本/导出检查通过；GUI内312个、CLI内201个项目模块与源码一致，与开发版相比仅版本常量变化。未重跑完整业务测试，开发阶段的专项验证另行保留，不将历史数量计为本次重测。[验证记录](https://github.com/KaysinBIT/arraylab/blob/v0.26.0/docs/validation.md)。

实际验收环境为本机Windows10，不代表干净系统、其它操作系统、全部显卡或雷达硬件验收。软件检查在推送前完成；发布后仅核对GitHub正式/Latest状态、标签和附件完整性。
