# ArrayLab v0.21.0

本版新增子阵中心位置优化、线阵三维方向图及图下主要指标，在同一工作台内完成参数设置、计算、比较和导出。v0.21.0 将已完成的 0.21.0.dev0 功能转为正式发行，计算模型与优化算法保持一致。

## 新增功能

- **子阵中心位置优化。** 在固定子阵数量、内部矩形模板及朝向的条件下，连续调整二维中心坐标，以降低指定扫描角和频率工况下的最差采样副瓣。每个工况均允许子阵公共相位和内部阵元相位随目标方向调整。约束覆盖展开后的实际阵元孔径、最小间距、中心禁布区及子阵模板包络重叠。
- **子阵结果查看与导出。** 在任务导航选择“子阵中心优化”，查看初始／最终布局、各工况方向图、正交主瓣切面和三维方向图；导出子阵中心、实际阵元及归属、幅相、指标、球面数据和图片。子阵数量与实际阵元数量分别报告。
- **线阵及馈电三维方向图。** 直线阵分析可在直角、极坐标和三维视图之间切换。直线阵馈电可选择目标激励、网络原始输出或电气模型输出作为三维来源，支持旋转、缩放和图片导出。
- **方向图下方统一指标。** 根据当前任务和模型提供主瓣／代表峰方向、3 dB 半功率宽度、正交大圆切面宽度、指向偏差、峰值方向性 D 及副瓣电平 PSL。摘要随所选记录、激励来源和工况更新，保存图片或复制图形时一起保留；缺少边界或模型信息时显示不可用及原因。
- **无头计算与有界多核。** 新增子阵无头入口，支持参数复算、独立搜索和结果导出；线阵无头输出增加三维 PNG 与完整球面 CSV。子阵多个独立搜索使用共享有界线程池，保留串行模式，并限制底层数值库线程，避免重复占用资源。

操作和指标定义见[子阵中心位置优化](https://github.com/KaysinBIT/arraylab/blob/v0.21.0/docs/subarray-centers.md)与[方向图、三维显示与主要指标](https://github.com/KaysinBIT/arraylab/blob/v0.21.0/docs/pattern-metrics.md)。

## 改进与修复

- 切换线阵历史记录或馈电激励来源时，三维图与指标均由保存的计算快照派生，不使用尚未运行的新输入，也不重新抽取随机误差。
- 图下摘要支持窄窗口自动折行；线阵和平面阵的扫描单点方向图也显示切面宽度与 PSL，扫描报告中的目标方向 D 保留原有名称。
- 子阵取消操作保留上一次成功结果；结果导出采用暂存后提交方式，避免将未完成文件当成结果。
- 统一子阵命令行的中文 JSON 编码为 UTF-8，修复 Windows 输出重定向时的编码问题。
- 将子阵预计算和最终复核纳入同一线程资源控制，阶段结束后恢复原有底层线程设置。

## 使用与限制

下载 `ArrayLab-0.21.0-windows-x64.zip`，完整解压后运行 `ArrayLab.exe`；保留整个目录及 `_internal`。源码与示例见 `ArrayLab-0.21.0-source.zip`，两个 ZIP 的校验值见 `SHA256SUMS-0.21.0.txt`。

桌面任务按“选择任务 → 设置参数 → 运行 → 核对结果 → 保存或导出”操作。脚本及无人值守运行使用同目录的 `ArrayLab-cli.exe`，每次使用尚不存在的输出目录：

```powershell
.\ArrayLab-cli.exe --elements 8 --scan-deg 20 --output-dir ".\results\linear3d" --plot all
.\ArrayLab-cli.exe subarray --write-example ".\my-subarray.json"
.\ArrayLab-cli.exe subarray --config ".\my-subarray.json" --output ".\results\subarray01" --plot all --workers 0
```

- **模型范围。** 子阵初版为相同矩形模板、固定朝向、等幅各向同性阵元；支持 1–64 个子阵、总计不超过 512 个实际阵元，以及最多 25 个角度与频率组合。没有重新划分子阵或优化内部几何，不据此推定控制端口数或 RF 链数。
- **指标口径。** 方向性 D 不等于包含损耗的增益 G。当前缺少辐射效率与完整损耗／失配输入，增益显示“未计算（缺效率）”。三维颜色表示相对场幅 dB，不是 dBi 增益。
- **空间波束。** 各向同性线阵的阵因子绕阵列轴对称；平面点阵上下半空间互为镜像。代表峰和局部切面宽度不承诺存在唯一空间波束。只有二维曲线的数据不能恢复三维场或全空间方向性；非各向同性稀疏单元仅有前半球响应时，不补造背面数据计算 D。
- **优化与副瓣。** 子阵 PSL 使用用户指定的 u/v 主瓣排除区；优化和加密、错位复核均属于有限采样，不保证连续域最坏峰或全局最优。复核结果比初始布局更差时保留初始布局，并在报告中标记。
- **记录范围。** 完整多次历史恢复仍限于直线阵分析与直线阵馈电；平面阵、二维稀疏与子阵优化使用各自的参数保存和结果导出。
- **继续暂缓。** 馈线物理尺寸、实体基板／封装、互耦、全波仿真和误差统计不在本版新增范围内。
