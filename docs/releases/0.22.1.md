# ArrayLab v0.22.1

本版采用包含天线阵列与波束元素的新图标，并将0.22.1.dev0的界面排版和馈电设计记录修复纳入正式发行。计算参数、电气算法及无头运行能力保持。

## 新图标

- 新主图标由3×3金色天线阵列、青色定向波束与波前组成，保留透明背景。
- 提供PNG原图与16–256像素的七尺寸Windows ICO，应用于桌面及命令行EXE，并用于桌面窗口和任务栏识别。

## 界面修复

- **顶部功能区。** 按实际文字高度排列按钮和分组标题，修复Windows字体度量下的纵向重叠。
- **小窗口与参数区。** 开始页、参数区和结果区支持滚动，修复短窗口下按钮裁切；保留方向图的可读尺寸。
- **图形与指标。** 平面阵和子阵切面为坐标文字与图下指标留出空间；窄窗多图比较自动纵向排列，新增换列逻辑只重排已有绘图对象，不重新综合阵列。
- **高DPI与任务切换。** 修复125%和150%显示缩放下稀疏图切换后的像素尺寸不匹配；隐藏任务页的大画布不再把当前任务结果区无谓撑高。

## 馈电设计记录

- 馈电页中间的“设计记录”支持再次选择当前项，恢复该记录的完整参数和已有结果。切换记录保留原报告、标签及保存值，不重新求解。
- 空记录列表显示明确提示；记录校验失败时保留当前记录和参数。
- 顶部“打开记录”支持由“导出结果”生成的完整`feed-network.json`，将其恢复为一条设计记录；继续兼容原历史记录和旧馈电比较文件。参数文件仍通过“打开参数”读取。

开发阶段已复现并修复同项重选没有触发恢复、切换记录未恢复输入、空列表缺少反馈，以及完整`feed-network.json`被拒绝的问题。标准多项下拉列表无法展开的现象在本机未复现；Qt事件检查不作为用户现场故障复现或原生操作系统鼠标手工验收。

操作范围见[计算记录指南](https://github.com/KaysinBIT/arraylab/blob/v0.22.1/docs/calculation-history.md)和[快速上手](https://github.com/KaysinBIT/arraylab/blob/v0.22.1/docs/quickstart.md)。

## 保留能力与边界

- 保留直线阵、平面阵、二维稀疏、子阵中心优化、三类馈电拓扑、逐支路匹配延迟、波束指向及三维方向图能力；本次不改变电气计算模型。
- 保留桌面和独立无头入口，以及现有的有界多核计算和资源保护。
- 运行包继续采用完整目录形式，本轮未实施依赖瘦身，也未改为单文件EXE或安装包。
- 馈线物理尺寸和误差统计继续暂缓；方向性D与包含效率、损耗的增益G保持区别。

## 下载与验证

下载`ArrayLab-0.22.1-windows-x64.zip`，完整解压后运行`ArrayLab.exe`。脚本和无人值守任务使用同目录的`ArrayLab-cli.exe`；移动程序时保留完整目录及`_internal`。

源码包为`ArrayLab-0.22.1-source.zip`，两个ZIP的SHA-256摘要列于`SHA256SUMS-0.22.1.txt`。原创源码采用MIT许可，第三方依赖保留各自许可。

本次正式版完成62项源码针对检查；独立程序通过942项Windows Qt检查和25项无头检查。两个EXE的7尺寸嵌入图标逐帧与认可ICO一致，75个冻结项目模块与源码一致，实际解压1226文件逐项SHA-256匹配。本机为Windows 10 Enterprise LTSC Build 19044，具体范围见[验证记录](https://github.com/KaysinBIT/arraylab/blob/v0.22.1/docs/validation.md)。0.22.1.dev0的开发阶段记录单独保留，不将旧检查计数标为本次重测。全部软件验证在推送前完成；推送后只核对GitHub标签、Latest、公开下载及附件完整性，不再运行软件测试。
