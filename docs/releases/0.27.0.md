# ArrayLab v0.27.0

0.27.0以功能验证、数值纠错、记录可靠性和模块维护为重点，附38页中文使用说明书。保留现有十个业务任务、原生三维场景、无头入口及文件格式，不增加新的物理建模假设。

## 算法与输入修复

- **3dB测宽的尺度稳定性。** 相同方向场仅改变公共幅度尺度时，旧实现可能把非零场误判为零场，或平方溢出并产生NaN。现在使用等价的半幅度条件，极端尺度先安全归一化；解析余弦场和两元半波长阵验证分别得到90°和60°宽度。
- **馈电功率分配的尺度稳定性。** 公开数值接口输入相同相对幅度、不同公共尺度时，原平方归一化可能输出NaN功率和线阻抗。现在先消除公共尺度再计算功率；1分2等功率50Ω负载仍得到各0.5功率、50√2Ω变换线。不能可靠表示的相对动态范围及非法幅度明确拒绝。

## 记录与文件可靠性

- JSON和NPZ元数据中的指数溢出（例如`1e999`）不再绕过有限数值检查。
- NPZ按精确成员名读写，避免`raw`与`raw.npy`相互混淆，并支持不与NumPy写入参数混用的合法数组名称。
- 拒绝NUL字符导致的数组名截断；错误输入不会用不可恢复的新文件覆盖原记录。
- 结果摘要校验和数组读取绑定同一已打开文件，避免校验后文件被替换而读入另一代数据。
- 补充NPY v3中文结构字段、Fortran顺序、读写成员上限及巨大数组头的兼容和边界检查。

## 模块维护

错误修复与结构重构分步进行。重复的端口功率归一化集中到同一私有实现，大圆半功率边界搜索与求根从结果组织中分离，JSON/NPZ解析及文件生命周期处理统一收敛。原公共签名、CLI、正常配置与记录格式保持；新增限制用于明确拒绝此前会产生NaN、歧义或不可恢复文件的非法输入。

## 验证与兼容边界

基线覆盖1959项用例，其中5处失败来自历史测试契约未同步，已核对并修正测试。数学修复先保留可失败的解析回归，再验证修复与重构；新增32项数学用例、16项记录/IO用例。最终78个测试入口、2007项用例全部通过，无失败、错误或跳过。既有测试、算法参考对照、性能测量与正式包检查分别记录，不将一个层次的通过数当作另一个层次的验收。

性能采用同环境、同输入的交替比较；普通余弦测宽中位耗时降低，32元ULA测宽和串馈完整设计分别有约0.054ms和0.57ms的小幅中位增加，样本区间重叠，所测可追踪内存峰值未增加。不能据此承诺所有输入都没有性能退化。
