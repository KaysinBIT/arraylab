# ArrayLab v0.22.0

本版加入逐支路匹配延迟和自定义二维稀疏阵列规模，改进稀疏综合的进度、取消及资源控制，并提升三维方向图旋转和缩放的响应。正式发行前同时核对并修正了串馈末级连接图。

## 新增功能

- **逐支路匹配延迟。** 每条固定90°阻抗变换支路可设置0–3600°匹配延迟，参与下游端口相位及末端扫描补偿。连接图分别显示T变换段、D匹配延迟段和C端口补偿；配置、计算记录、CSV/JSON和无头入口保存对应参数与路径累计值。
- **自定义二维稀疏规模。** Nx、Ny和目标阵元数K采用正整数输入，取消原4–20偶数网格和K≤400界面限制。支持奇数网格、单行/单列及符合中心对称条件的奇数K，设置保存和恢复不会静默截断大整数。
- **线性规划求解器选择。** 自动模式对较大的minimax问题使用内点法，也可显式选择原求解器。完整约束、采样网格、综合方法及迭代数保留，结果记录实际求解器和约束残差。

操作详见[支路匹配延迟](https://github.com/KaysinBIT/arraylab/blob/v0.22.0/docs/branch-electrical-lengths.md)和[二维稀疏阵列](https://github.com/KaysinBIT/arraylab/blob/v0.22.0/docs/sparse-arrays.md)。

## 修复与性能

- **串馈末级示意图。** 普通串馈和1分2后对称串馈的最后一条续传支路，从末级节点底部延续主干，再接到末负载，避免被误读为另一个侧向抽头。T、D、C标注位置和数值保留，电气阻抗、功率与相位计算不变；单端口匹配和双端口输入等分的边界结构保留。
- **稀疏综合响应与取消。** 桌面综合及加权使用独立计算进程，显示阶段和耗时；取消或关闭时回收进程，失败、取消及结果显示异常均保留上一份成功结果。开发阶段默认20×20、K=36算例约从23秒降至7秒，取消约0.07秒；这是本机指定工况记录，不是统一耗时承诺。
- **大规模资源保护。** 按候选数、工况、采样和并行数预检内存，Windows后台进程另有作业内存上限。方向图、距离、共阵及积分分块处理，不自动减少K或采样密度；预算不足时保留可保存的参数并说明原因。
- **三维旋转与缩放。** 四类三维方向图合并连续绘制请求，拖动时使用保留主轴截面和已有峰值的轻量预览，松开或保存图片时恢复完整曲面；支持滚轮缩放，显式清理旧视图事件。开发阶段200元线阵/馈电本机实测约从8帧/秒提高到28帧/秒。
- **图下指标与排版。** 复用已计算的适用指标，缓存同一快照摘要和文字布局；三维预览不改变计算网格、激励、峰值、3dB宽度、方向性及副瓣指标。

三维操作见[交互说明](https://github.com/KaysinBIT/arraylab/blob/v0.22.0/docs/3d-interaction.md)。

## 模型边界与兼容

- 匹配延迟是当前设计频点的理想无损模型，其特性阻抗等于下游等效电阻；固定90°变换段仍保留。不换算实体线长，也不提供固定物理网络的宽带匹配。
- 馈电配置和结果使用schema 3，兼容旧配置1、2；旧记录按零支路延迟读取并保留保存值。改变拓扑或阵元数后须重新设置或清除支路绑定，旧版程序不能读取新格式。
- 自定义规模不代表任意输入都可计算。K仍受候选数量、中心对称、禁布区、最小间距和资源约束；奇数K需要奇数×奇数网格且中心可用。没有可评价副瓣区域的小孔径会明确报错。L1加权结果仍是可变阵元数对照。
- 稀疏规模开放不改变平面阵馈电接收的200阵元、40λ孔径及各向同性点源限制。大孔径结果仍是有限网格估计，不能当作连续角域上界。
- 不同求解器可能选择不同退化最优解，进而改变L1布局；不保证所有布局相同或副瓣更低。需复现旧算法时可选择原求解器。
- 方向性D不等于包含效率和损耗的增益G。馈线物理尺寸、互耦、全波分析和误差统计继续暂缓。
