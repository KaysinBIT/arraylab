# ArrayLab v0.23.0

本版为各模块增加独立图标，并将直线阵到馈电设计、自动计算历史、二维稀疏导航和并排图形纳入正式发行。桌面与独立无头入口继续提供，电气模型和既有结果格式保持兼容。

## 模块导航与图标

- 为开始页、直线阵分析、直线阵馈电、平面阵馈电、二维稀疏、子阵中心优化和多角度评估设计不同图标，以阵元排列、馈电分支、二维网格、稀疏位置、子阵分组和扫描角等形状区分入口。
- 同一模块在开始页、左侧导航、任务菜单、标签页及相关工具栏入口使用一致的图标。保存、打开和运行等通用操作仍使用原有操作图标。
- 保留包含金色天线阵列与青色波束的应用主图标，模块图标用于识别工作内容。

[查看模块图标对照](https://github.com/KaysinBIT/arraylab/blob/v0.23.0/docs/images/module-icons.png)。

## 自动历史与馈电流程

- **直线阵自动历史。** 每次成功按F5计算后自动留存，关闭并重启后恢复。“叠加比较”只控制曲线显示，不删除历史记录。
- **将阵列导入馈电。** 选中一条已计算的直线阵后，点击顶部“将该阵列导入馈电设计”，恢复该快照的阵列与扫描角，再按F5生成馈电设计。待计算输入不会混入已选结果；原馈电结果保留到重新生成。
- **二维稀疏自动历史。** 每次成功综合或加权保存完整快照。“本次综合方案”展示当前各方法结果，“历史计算记录”保存不同运行批次，重启后可按需读取。
- **恢复与失败保护。** 稀疏历史恢复参数、方案和已保存指标，不重新优化；仍进行必要的格式、几何校验与绘图。失败或取消不增加成功记录，存储或恢复失败保留原档案与当前结果。

操作细节见[计算记录指南](https://github.com/KaysinBIT/arraylab/blob/v0.23.0/docs/calculation-history.md)和[直线阵到馈电设计](https://github.com/KaysinBIT/arraylab/blob/v0.23.0/docs/linear-feed-handoff.md)。平面阵馈电与子阵中心优化尚未提供完整的多次自动历史恢复。

## 二维稀疏并排显示

- 默认主视图左侧显示阵列布局，右侧显示二维方向图，下方保留主要指标。两个图共享所选方案、工况、场类型及理想/量化相位设置。
- 左侧可直接进入并排图、扫描切线、阵元幅相、工况指标、方法比较、加权和说明；其他分析集中在“更多分析”，单图入口继续保留。
- 左侧方案/历史与中间控件同步，切换视图不启动综合或加权。计算期间阻止切换方案或历史，避免覆盖正在运行任务的上下文。
- “放大图形”和“保存当前图形”保留当前并排画面；窄窗口可滚动查看完整图及指标，旧历史中的单图选择仍可恢复。

## 修复与性能

- 修复馈电页选择“最终输出”却仍自动叠画未补偿曲线的问题。默认只显示所选来源；需要目标、未补偿和最终曲线同时显示时，选择“补偿前后对比”。二维、极坐标、三维及图下指标的来源保持一致。
- 网络未补偿相位造成的真实波束偏转仍可单独查看，不隐藏实际电气结果，也不通过修改正确的相位公式强行移动主瓣。
- 二维稀疏启动只读取历史摘要，进入或点选时加载一个完整快照，避免一次读取全部历史正文。
- 稀疏图缩放复用已画场数据与指标文字，仅重新排版，不重复采场或综合；修复延迟重排替换工具栏后导致平移复位失效的问题。

## 测试入口与范围

新增`--smoke-suite sparse-view`，将并排图、稀疏导航和自动历史集中为专项检查；报告分别记录范围、通过项与各组耗时。移除重复的“仅判断存在坐标轴”检查，保留场数据与指标一致性、真实选择/平移/放大/导出和历史恢复验证。默认完整回归入口不变，专项通过不代表其他工作台或大阵列性能已经重测。

本版正式验收结果及环境限制见[验证记录](https://github.com/KaysinBIT/arraylab/blob/v0.23.0/docs/validation.md)。开发阶段结果单独保留，不将旧版通过数量计为本次重测。软件验证安排在推送前；推送后仅核对标签、Latest、公开下载及附件完整性，不再执行软件测试。

本轮947项回归及42项子检查通过；最终独立程序通过1068项Windows Qt完整检查和25项无头检查，模块图标另通过99项真实Qt检查。缩放复位修复后98项相关绘图检查重新通过。85个冻结项目模块与源码一致，解压1233个文件摘要匹配。实际环境为Windows 10 Build 19044，不代表干净电脑或其他系统已验收。

## 保留能力与边界

- 保留三类馈电拓扑、逐支路匹配延迟、波束指向、三维方向图、有界多核与独立无头运行能力。
- 馈线物理尺寸和误差统计继续暂缓；方向性D与包含效率、损耗的增益G保持区别。
- 稀疏综合仍采用已说明的理想/标量单元模型与有限采样评价，不等同于全波仿真或连续角域性能保证。
- 运行包仍为完整目录形式，无需安装Python；移动时必须保留整个目录及`_internal`。
