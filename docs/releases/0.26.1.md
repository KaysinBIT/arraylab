# ArrayLab v0.26.1

0.26.1 同步相控阵和雷达方程子模块已完成的数值与判定修复，保留现有操作界面、FMCW/脉冲三维场景和无头入口。

## 相控阵综合

- 同步ArrayStudio 1.2.2：修复一维综合基准约束保护、粗细采样相位量化不一致、超大相位及极小激励的数值稳定性。
- 分离绘图下限与真实分析数值，细化峰值与3dB宽度，修正退化轴、不可见主阶和主瓣截断判定。
- 小旁瓣排除区域不能绕过截断检查；可行性、旁瓣改善与细复核回退分别保留。

## 雷达方程验证

- 同步EquationLab 1.0.1：修复FMCW/多径相位、分数时延匹配、Hann窗支撑与接收滤波的一致性。
- 固定CUT概率、目标关联和多目标背景触发分别核算，避免错误“达标”；修正多look参考口径及随机种子碰撞。
- 加强实际频带、FIR历史/尾部、远场、反算与内存预算检查；图表和导出使用明确的新指标名称。

## 记录与兼容

- 旧记录保留原数值，界面和导出明确标记旧算法来源，需重算后才能作为新版结论。
- 旧H0校准禁止复用；需以新版模型重新校准并独立验证。
- 检测CSV明确使用`cell_power_to_noise_db`，旧统计导出使用`legacy_*`列名；依赖旧列名的脚本需适配。JSON保留原检测字段兼容别名，历史数值不改写。
- PulseLab 1.0.1、WaveLab 1.4及二维稀疏现有数值内核无需重复同步，原项目与独立实验目录未改动。
