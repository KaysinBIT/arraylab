# ArrayLab v0.25.0

0.25.0 将此前开发阶段的稀疏雷达 MIMO、WaveLab 1.4 雷达设计、统一任务树及拖动响应优化纳入正式发行。提供 Windows x64 桌面程序和独立无头命令行，无需另行安装 Python、Node.js 或原 WaveLab 工程。

## 新增功能

- **一维与二维雷达 MIMO。** 分别设置 Tx/Rx 坐标和数字幅度，查看虚拟和阵列、通道映射、独特位置、重数、孔径及数字波束指标。已有直线阵和二维稀疏结果可导入 Tx 或 Rx。支持完整记录、CSV/PNG 和无头计算。
- **FMCW 与 A/B 双波形。** 原生界面支持 TDM/DDM、两组独立参数、分段/整轮交替、距离/速度频谱、帧时序和两类距离解模糊实验。支持最多8份方案对比及完整记录。
- **雷达天线反向设计。** 按 Tx/Rx 数、角分辨目标、孔径、间距及旁瓣约束搜索一维方位或俯仰布局。可以验证当前阵列，或将综合坐标应用到雷达布局，并固定物理参考频率。
- **高分辨角度判据。** 增加 MUSIC、Capon/MVDR、LS-ESPRIT、DML；提供有限含噪快拍、空间平滑、逐扫描中心验证及适用性说明。候选筛选和最终验证使用独立种子。
- **天线增益预算。** 根据 RCS、距离、传导功率、实际 ADC 积累、窗损耗、Rx 合并和 SNR 要求反算每通道 Tx/Rx 增益；可分别核算 A/B 后取较严要求。

[MIMO 操作与模型边界](https://github.com/KaysinBIT/arraylab/blob/v0.25.0/docs/mimo-arrays.md) · [雷达设计操作](https://github.com/KaysinBIT/arraylab/blob/v0.25.0/docs/radar-waveforms.md)

## 界面与使用流程

- 七个业务模块均可在左侧展开，直接进入结果视图或定位右侧参数页，与中间控件双向同步。
- 馈电设计记录在树中同步显示，沿用已有记录恢复方式；保留直线阵、二维稀疏的自动历史。
- 雷达 F5 分析波形、天线与增益；耗时的稀疏综合和高分辨验证由独立按钮启动，打开配置或切换视图不自动搜索。
- 应用雷达综合坐标后再按 F5，可保留此前独立综合快照，并注明原参考频率与“未重新验证”。

## 修复与性能

- 拖动左右栏分隔线时缩放已有画面作临时预览，停止后按最终尺寸完整排版，避免每步重复绘制。计算数据、缩放范围、三维相机及高分辨率图片输出保持不变。
- 修复导航刷新抢走子项高亮、馈电损坏记录恢复后的选择回退，以及记录显示失败时的参数页回滚。
- 加强雷达记录结构检查，保留正常未达标/算法不适用结果，拒绝缺失指标或损坏图形数据。
- 框架启动、应用组装、业务模块与公共组件职责分开，保留旧导入和命令入口。数值任务继续支持有界多核和单核模式。

开发阶段本机基准中，40步分隔线拖动从60次完整绘制降到停止后的1次。该结果针对指定窗口和模型，不作为所有电脑、所有图形的帧率保证。[拖动验证口径](https://github.com/KaysinBIT/arraylab/blob/v0.25.0/docs/resize-responsiveness.md)

## 兼容与范围

- 可读取原有直线阵、馈电、二维稀疏和 MIMO 记录；历史目录与数据库位置不变。雷达参数/结果支持新 schema 2，并读取旧 schema 1；WaveLab schema 1/2/3 可导入。旧程序不保证读取新版新增记录。
- MIMO 页的数字波束不等于真实辐射增益；雷达增益预算单独依据输入条件计算。
- 高分辨实验固定已知双目标，最多48个独立位置，依赖可分离、已校相的观测；经验通过率不是 Pd、置信下限或硬件分辨率保证。
- 物理尺寸设计、误差统计专题、互耦/极化、完整全波仿真、DDM 盲解码和跨 A/B 相干融合继续不在当前实现范围。

## 发布验证

本次整理只修改正式版本号、启动路径和发行材料，业务实现沿用已验证的0.25.0.dev4。发布前核对最终运行包的源码一致性、桌面启动/拖动、无头版本与报告导出，以及压缩包完整性；未重跑全量业务测试。开发阶段验证与本次发布核验分别记录，不把历史通过数量计为本次重测。

实际验收环境为本机 Windows 10；不代表干净系统、其他操作系统或真实雷达硬件验收。软件检查均在推送前完成，发布后只核对标签、Latest 和附件字节。[完整验证记录](https://github.com/KaysinBIT/arraylab/blob/v0.25.0/docs/validation.md)
