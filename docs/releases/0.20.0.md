# ArrayLab v0.20.0

ArrayLab 用于直线阵、平面阵和理想馈电网络的电气分析，提供 Windows 桌面工作台与无头命令行。本版整合已完成的工作流、计算记录、波束指向、二维稀疏设计和多核能力，以 v0.20.0 正式发布，延续现有计算模型与算法。

## 使用入口

启动后先选择任务，再按“设置参数 → 运行计算 → 核对结果 → 保存或导出”的顺序操作。四类任务共用一个工作台：

| 任务 | 适用工作 |
| --- | --- |
| 直线阵分析 | 查看均匀直线阵的方向图、扫描变化、阵元激励、方向性和半功率宽度 |
| 直线阵馈电 | 设计功分网络与端口补偿，核对支路阻抗、连接图、幅相和输出方向图 |
| 平面阵馈电 | 为规则矩形阵或任意 x-y 坐标布局设计馈电，查看切面、三维阵因子与端口表 |
| 二维稀疏设计 | 从候选位置选择阵元、比较约束与加权方案，并继续转入平面阵馈电 |

进入任务不会自动计算。顶部工具栏、菜单和 F5 跟随当前任务；右侧设置参数，中间查看结果。首次使用可阅读[五步快速上手](https://github.com/KaysinBIT/arraylab/blob/v0.20.0/docs/quickstart.md)。

## 本版包含的主要功能

- **三种馈电拓扑与波束指向。** 支持并联树形、串行逐级抽头、1 分 2 后对称串馈，计算理想功分网络的支路阻抗和 λ/4 变换线阻抗。对称串馈要求偶数阵元及镜像目标幅度。直线阵设置目标 θ，平面阵设置目标 θ/φ；选择“按目标指向补偿”后运行，核对目标、未经补偿和模型输出。仅修改目标角不会自动切换相位模式。
- **幅相与扫描核对。** 支持均匀、Chebyshev、Taylor 和自定义幅相输入，以及相位量化、固定种子的单次幅相误差和失效端口。多角度评估提供直线阵 θ 扫描、平面阵 θ 或 φ 扫描、逐点方向图及端口补偿相位。
- **规则与任意坐标平面阵。** 支持 Nx×Ny 布局及 `element,x,y` 坐标 CSV，最多 200 阵元、最大两阵元距离 40λ；提供二维切面、上半球图和可旋转的全空间三维阵因子。
- **原生二维稀疏工作台。** 在 ArrayLab 主窗口内完成规则/随机对称抽稀、贪心交换、模拟退火和重加权 ℓ1，设置中心禁布区、最小中心距，并进行同一布局的 minimax/Taylor/Chebyshev/Gaussian 加权、多角度/多频率共同综合及相位量化复核。运行包不依赖原独立 Demo 目录。
- **稀疏布局联动馈电设计。** 所选方案与工况的理想坐标、相对幅度、频率和扫描角可送入平面阵馈电，从可编辑的 50 Ω 并联网络初值继续设计。联动限于兼容的各向同性方案及电气页容量、孔径和幅度范围；原量化相位码不迁移。
- **有界多核与无头运行。** 扫描点、平面阵三组方向图和稀疏方案复核可并行。桌面可选自动（最多 4 路）、单核或 2–8 路；小任务自动串行，实际路数受可用资源与任务数限制。命令行支持 `--workers`，并保留无界面计算、配置复算和数据/图像导出。

## 操作与记录改进

- 将四类任务的计算、参数、保存和导出入口统一到当前任务上下文，避免跨任务操作混用；消息面板默认收起，可恢复工作布局。
- 直线阵和直线阵馈电支持保存、重新打开最多 5 条计算记录，恢复曲线、参数快照、标签、选中项和已有结果，无需重算；兼容旧版馈电比较文件。
- 明确区分“保存参数”“保存记录”和“导出当前结果”。修改输入后，已有图形和指标仍对应上次计算，重新运行后才更新。
- 同一设计的多角度评估窗口关闭后再次打开，保留本次主程序会话内的设置与结果。

详见[计算记录与文件选择](https://github.com/KaysinBIT/arraylab/blob/v0.20.0/docs/calculation-history.md)和[多核范围与资源控制](https://github.com/KaysinBIT/arraylab/blob/v0.20.0/docs/multicore.md)。

## 下载与运行

| 附件 | 用途 |
| --- | --- |
| `ArrayLab-0.20.0-windows-x64.zip` | Windows x64 便携运行包，无需另装 Python |
| `ArrayLab-0.20.0-source.zip` | 源码、文档及示例 |
| `SHA256SUMS-0.20.0.txt` | 上述两个 ZIP 的 SHA-256 校验清单 |

完整解压便携包后运行 `ArrayLab.exe`。移动程序时保留整个目录及 `_internal`，不要单独复制 EXE。脚本、输出重定向和调度任务使用同目录的 `ArrayLab-cli.exe`：

```powershell
.\ArrayLab-cli.exe --elements 20 --frequency-ghz 3 --spacing 0.5 --scan-deg 30 --output-dir ".\results\run01" --plot both
```

每次计算使用新的输出目录；已有目录不会被覆盖。查看命令参数可运行 `ArrayLab-cli.exe --help`。

从源码运行时，在源码目录创建 Python 环境并安装桌面依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install ".[desktop]"
.\.venv\Scripts\python.exe -m arraylab
```

源码无头入口为 `python -m arraylab --headless` 或 `python -m arraylab.cli`。完整用法见 [README](https://github.com/KaysinBIT/arraylab/blob/v0.20.0/README.md)。

## 验证与已知范围

本次发布前，50 项版本/参数相关源码检查通过；解压后的 0.20.0 EXE 完成 377 项桌面交互和 22 项无头检查。完整记录见 [docs/validation.md](https://github.com/KaysinBIT/arraylab/blob/v0.20.0/docs/validation.md)。运行环境为 Windows 10 Enterprise LTSC Build 19044；未完成 Windows 11、干净系统及 Linux/macOS 的完整验收。

- 电气分析采用各向同性点源、无互耦、无地平面及中心频点的理想无损网络。三维图是阵因子，不是全波或实体电磁模型；方向性不等于包含损耗的增益。
- 多峰、天顶及全失效等情况保留未定义指标；平面阵代表峰的球面角距不承诺唯一波束指向误差。多角度评估报告指定目标方向的响应，不代替峰值跟踪或宽带分析。
- 馈线物理尺寸、基板与工艺设计、实际器件损耗和误差统计继续暂缓；当前单次误差实现不等于蒙特卡洛统计结果。
- 完整多次历史恢复目前仅支持直线阵分析与直线阵馈电。平面阵和二维稀疏使用各自的参数保存与结果导出；扫描跨进程结果恢复及包含窗口布局的完整项目持久化尚未支持。
