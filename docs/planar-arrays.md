# 规则与任意坐标平面阵（0.20.0）

从开始页或左侧选择“平面阵馈电”（F7），右侧显示本任务的独立参数，进入时不自动计算。共用三种馈电拓扑、相位补偿、自定义幅相、量化、随机误差和匹配失效模型。中间输出坐标、切面、上半球图、全空间三维阵因子和网络表。

## 明确范围

- 所有阵元为位于z=0平面的各向同性点源，无互耦和地平面，不赋予极化或实体尺寸。
- 1–200阵元，最大两阵元距离40λ，任意坐标绝对值不超过1000λ，最小阵元距离10⁻⁶λ。范围是本版计算规模约束，不是参考说明书或制造限制。
- 规则阵：Nx×Ny，x/y方向等间距，坐标自动围绕原点居中；编号按x方向先变化，再逐行增加y。
- 任意阵：CSV表头`element,x,y`，编号从1连续，恰好两维坐标；z固定0。坐标顺序就是端口顺序，保留用户原点，不自动重排。
- 坐标中的λ为自由空间波长c/f，单位可用λ或mm；改变单位会按新单位解释输入值，不自动换算。频率用于mm与λ的转换。

```csv
element,x,y
1,-1,-0.3
2,-0.3,0.6
3,0.2,-0.5
4,0.8,0.7
5,0.5,0.1
6,-0.7,-0.8
```

## 角度与激励

右侧常驻目标θ、φ，下面“布局、切面、阻抗、幅相、误差”依次设置设计条件。在“幅相”中选择“按目标指向补偿”（新设计默认），点击顶部“生成平面阵设计”或F5，按实际x-y坐标计算端口相位，适用于规则阵、任意坐标阵和二维稀疏页转入的布局。计算保留所选相位模式。切面φ在“切面”页单独设置，不自动跟随目标φ。

扫描θ从+z轴量起，0–90°；扫描φ从+x朝+y为正，−180–180°。目标扫描相位为

\[
\phi_n^*=-360^\circ[(x_n/\lambda)\sin\theta_0\cos\varphi_0+
(y_n/\lambda)\sin\theta_0\sin\varphi_0]+\phi_{n,\mathrm{offset}}.
\]

正侧向补偿把θ₀置0。任意附加相位可改变实际主瓣，扫描参数只是基准。天顶θ=0时φ无唯一意义，报告为null；单个有源阵元时不报告代表峰方向。

页面分别显示有效目标与上半球输出代表峰，并给出两方向单位向量间的球面角距。该角距只比较所报告代表峰，不代表唯一波束的指向误差；其他等高峰及前后对称仍可能存在。非相干峰继续标注“数值估计”，不将角度网格的最高点冒充精确峰。

JSON的`electrical.pointing`含请求θ/φ、有效目标θ/φ、相位模式、`output_representative_theta_deg`、`output_representative_phi_deg`、`representative_peak_separation_deg`及搜索方法。`peak_is_not_claimed_unique`保持true。正侧向时目标φ为null；全失效或单有源阵元时代表峰及角距无定义。设置格式不变，可直接由`--planar-config`无头复算。

二维切面固定φ，横坐标采用有符号θ=-90…90°，始终位于z≥0半空间。负θ对应切面另一侧，不能把它直接当成全空间球坐标的负极角。

规则矩形阵的Chebyshev/Taylor采用x、y两方向权重的乘积。Taylor nbar不能超过任一大于1的轴向阵元数。任意阵的命名加权按输入端口顺序生成，不自动解释为径向或空间对称加权；需要特定空间分布时应导入逐端口幅相CSV。

## 馈电连接的含义

网络按端口编号综合。对称串馈仍要求偶数端口及幅度编号镜像，但任意坐标中的Pi与P(N+1−i)不一定在空间上镜像。网络SVG表达逻辑连接，不代表实际x-y走线或物理长度。相位补偿由实际坐标计算，不能由连接图上的几何距离推断。

## 全空间指标与三维图

场因子直接由复激励和二维坐标求和。各向同性阵元的全空间平均功率使用

\[
\frac{1}{4\pi}\int |F|^2\,d\Omega
=\sum_{m,n}w_mw_n^*\operatorname{sinc}(2|\mathbf r_m-\mathbf r_n|/\lambda),
\]

其中sinc(t)=sin(πt)/(πt)。方向性是全空间最大辐射强度除以该平均功率，不能当成效率或增益。数值抵消严重时用球面求积回退。

若相位满足某个可见方向的相干条件，峰值使用相干和上界。否则在可见方向余弦圆盘上搜索，网格边长M=max(81,ceil(16D)+1)，D为最大孔径/λ，再对局部候选进行约束优化。报告保留搜索步长，并明确标记`disk_grid_multistart_estimate`。该搜索是数值估计，不是任意病态激励下的全局极值证明。

报告给出一个代表峰方向，不承诺唯一主瓣：平面阵前后半空间天然对称，还可能有栅瓣或其他等高峰。当前不报告平面阵唯一HPBW，以免把某一切面的宽度当成二维波束的完整描述。

三维图半径为相对场幅度，0 dB参考为目标激励的相干幅度和。球面图按θ、φ各3°采样；可能漏掉窄瓣，不能用显示网格代替峰值指标。二维切面步长独立可调。三维视图支持鼠标拖动旋转；无头导出为静态PNG。它是阵因子，不是全波结果或CAD实体。

## 保存和无头运行

当前开发版平面阵使用独立格式`arraylab.planar_electrical`、schema_version=2，保存完整几何与电气设置，并兼容旧schema 1。导入配置中的支路延迟会保持，阵元数或拓扑绑定错误时拒绝计算；逐支路编辑窗口本轮位于直线阵馈电页。无效设置、重合坐标或错误CSV在应用前拒绝；已有图形和导出继续对应上次成功生成的快照。

```powershell
python -m arraylab --headless --planar --nx 4 --ny 4 --scan-theta 30 --scan-phi 45 --cut-phi 45 --feed-network symmetric_series --output-dir results/planar --plot all
python -m arraylab --headless --planar --coordinates examples/planar-coordinates.csv --coordinate-unit lambda --scan-theta 33 --scan-phi 47 --cut-phi 47 --output-dir results/arbitrary --plot all
python -m arraylab --headless --planar-config examples/planar-arbitrary.json --output-dir results/reloaded --plot all
```

使用`--planar --help`查看参数。平面阵与直线阵配置不能混用；`--elements`、`--spacing`等直线阵选项不会被静默忽略，而是明确报错。`--plot`支持none、cut、map、3d、all。

导出包括`planar-config.json`、完整报告、端口/网络阻抗CSV、可往返读取的坐标CSV、三条切面CSV、球面采样CSV、逻辑馈电SVG及按需的三类PNG。导出新目录，不覆盖已有目录；全部生成成功后才显示目标目录。

0.7.1另导出`planar-cut-target.dat`、`planar-cut-uncompensated.dat`、`planar-cut-output.dat`，对应上次成功生成的目标、未补偿及模型输出切面。每份DAT为无表头的有符号θ°、幅度dB两列，使用12位有效数字；不重新归一化，也不从尚未计算的新输入生成曲线。可在主工作台“读取数据”作比较。DAT不包含切面φ、坐标单位、相位或全空间指标，需与同目录的`planar-report.json`一起保留；不能由导入切面反推方向性。

验证采用球面独立求积、2×2阵闭式结果、退化直线阵、坐标平移/旋转不变性、同一方向的二维/三维交叉核对及最大200阵元案例。实际基板、馈线路径、极化、互耦、损耗和目标电脑的运行验收仍不由这些数值测试替代。

0.8.0可从本页已生成设计进入[多扫描角电气评估](scan-study.md)，按θ或φ批量扫描。扫描保持另一角和切面φ不变；指标直接在指令方向计算，不能将固定切面的峰值当成当前扫描方向的响应。
