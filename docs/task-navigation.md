# 左侧任务树

从0.25.0.dev3起，七个业务模块均可展开，按已有结果视图和参数页组织。点击模块名称进入并展开该模块；点击子项切换对应页面。其他分支的手动展开状态保留，可使用三角箭头收起，滚动查看长列表。长名称会省略显示，悬停可查看完整名称。

| 模块 | 结果与记录子项 | 参数入口 |
| --- | --- | --- |
| 直线阵分析 | 方向图、方向图数据、阵元激励、阵列模型、原有历史计算记录 | 参数设置 |
| 直线阵馈电 | 支路参数、连接示意、端口与相位、方向图核对；方向图下有直角/极坐标/三维；本会话设计记录 | 阵列与目标指向、馈电网络、幅相加权、误差失效 |
| 平面阵馈电 | 阵元坐标、二维切面、上半球方向图、全空间三维、端口幅相、网络阻抗 | 布局、切面、阻抗、幅相、误差 |
| 二维稀疏设计 | 原有并排布局/方向图、扫描切线、阵元幅相、工况、更多分析、综合方案和自动历史 | 直接定位原有四个参数页 |
| 子阵中心优化 | 布局、二维方向图、主瓣切面、三维方向图 | 子阵、孔径、扫描、优化 |
| 稀疏MIMO分析 | 物理/虚拟布局、切面、二维图、通道映射、独特位置 | 模型与扫描、Tx、Rx |
| FMCW雷达波形设计 | 波形与解模糊结果、天线设计结果、三维场景、方案对比、公式说明 | 共用/A-B、A、B、ADC恢复、跨周期；天线设计下展开布局、反向设计、高分辨条件、增益预算；三维显示设置位于场景上方 |

结果下拉框、结果标签页、右侧参数页与左侧高亮双向同步。刷新工具栏不会把选择跳回模块父节点或强制选回历史行。点击参数入口会显示对应右侧参数区；不会运行F5计算、综合或导出。

直线阵与二维稀疏沿用各自已有的历史行为。馈电“设计记录”映射已有的本会话下拉列表，选择恢复保存的输入和结果，不重新设计；编辑输入后双击同一记录或按Enter，可以重新恢复该条。改名、增加或打开记录会更新树。此修改不新增自动历史数据库，MIMO、平面阵、子阵和雷达也没有虚构的历史列表；完整记录仍通过顶部按钮保存或打开。

开发验证可使用`python -m arraylab --smoke-test tmp/navigation --smoke-suite navigation`，只覆盖导航及其直接影响。冻结包使用同名参数；不需要运行全部数值测试或所有桌面验收。
