# 说明书源码与重建

`使用说明书.md`是可编辑的分页Markdown模板，`{{VERSION}}`由生成器替换。显式分页使章节与目录页码保持一致；不要把未替换的模板直接当成正式说明书。

在项目根目录，使用单独的文档环境安装ReportLab和pypdf，然后执行：

```powershell
python -m pip install reportlab pypdf
python tools/build_manual.py --version 0.27.0
```

默认输出为`output/pdf/ArrayLab-0.27.0-使用说明书.pdf`；可用`--output`指定其它文件。生成器不导入ArrayLab或Qt，也不会运行任何数值任务。字体位于`fonts/`，许可和变换来源一并保留；PDF按实际使用字符嵌入子集。

重建后至少核对：PDF页数与模板分页数量一致、中文能够提取/搜索、命令和示例路径仍存在；使用Poppler的`pdftoppm`逐页渲染检查文字、表格、截图及页码。标题、正文或截图有变化时，应重新检查生成结果，不把旧的渲染检查当作新文件验收。

截图均来自仓库已有真实界面，正文已标明来源版本，仅说明操作位置与结果来源，不声称是当前新一轮软件测试的截图。若更换截图，请保留完整画面比例和来源说明。

生产程序运行不需要ReportLab、pypdf或本目录的完整字体文件。发布时将最终PDF放在程序旁，并单独作为Release附件；本目录和生成脚本保留在源码中。
