# 五步快速上手

适用于ArrayLab 0.13.0。启动后先选任务；参数在右侧，结果在中间，计算、保存与导出集中在顶部。进入任务不会自动计算。

![开始页与操作流程](images/workflow-home.png)

## 先选对任务

| 你要做什么 | 开始页选择 | 接下来主要设置 |
| --- | --- | --- |
| 看均匀直线阵的方向图与扫描变化 | 分析直线阵 | 频率、阵元数、间距、扫描角 |
| 为直线阵设计功分网络和端口相位 | 设计直线阵馈电 | 直线阵几何、拓扑、阻抗、目标角与幅相 |
| 为矩形阵或任意x-y坐标布局设计馈电 | 设计平面阵馈电 | 二维布局、频率、目标θ/φ、切面与馈电 |
| 从候选位置选取阵元并比较稀疏方案 | 综合稀疏阵列 | 候选网格、保留阵元数、约束与综合方法 |

直线阵分析与直线阵馈电共用直线阵几何输入。切到馈电任务后，右侧显示馈电设置，中间核对馈电结果。平面阵的布局、频率和角度独立设置。

## 每次计算按这五步走

1. **选择任务。** 点击开始页卡片，或使用左侧任务导航。顶部“开始”或Ctrl+Home可以回到开始页。
2. **设置参数。** 在右侧输入，或点“工作 → 打开参数”载入当前任务的参数文件。馈电要按指定目标扫描时，在“幅相加权”（平面阵为“幅相”）中选择“按目标指向补偿”。仅填写目标角不会改变相位模式。
3. **运行计算。** 按F5，或点击顶部当前任务的运行按钮：计算直线阵、生成馈电设计、生成平面阵设计或开始稀疏综合。稀疏综合运行时可用顶部“取消计算”。
4. **核对结果。** 在中间查看方向图、表格及模型；馈电优先核对支路阻抗、端口幅相和输出方向图。看多次直线阵结果时，用“结果”下拉框选择；馈电使用“设计记录”。
5. **保存或导出。** 需要下次重算，保存参数；需要下次直接看已有直线阵/直线阵馈电结果，保存记录；需要交给其他软件使用，导出当前结果。

改参数后，已有图形与指标仍对应上次计算。再次按F5才会生成新结果；此时“保存参数”保存新输入，“保存记录”和“导出当前结果”保存已有结果。

## 例一：查看直线阵扫描

选择“分析直线阵”，在右侧填入下表，然后按F5。这组值用于熟悉操作，不预设结果指标。

| 参数 | 输入 |
| --- | --- |
| 频率 | 3 GHz |
| 阵元数量 | 8 |
| 中心间距 | 0.5，单位选λ |
| 相位设置 | 指定扫描角 |
| 扫描角 | 20° |
| 采样步长 | 0.1° |

在中间依次查看“1D方向图”“方向图数据”“阵元激励”和“模型示意”。要比较另一个角度，先勾选“保留并比较（最多5条）”，将扫描角改成−20°，再按F5。用“结果”下拉框选择要核对和导出的记录。

外部方向图从“文件 → 读入外部曲线（直线阵）”导入，支持角度、幅度及可选相位列。外部曲线不会被当成本软件算出的阵列结果，也不会由单个切面推断方向性。

## 例二：生成直线阵馈电设计

选择“设计直线阵馈电”，设置3 GHz、8阵元、0.5λ间距。右侧“馈电网络”选择“1分2＋对称串馈”，输入、节点和负载阻抗均设50 Ω；目标波束θ填−24°。在“幅相加权”选择“按目标指向补偿”和“均匀幅度”，初次操作可保留零误差、无失效和连续相位设置。

点击顶部“生成馈电设计”或按F5，随后查看“支路阻抗”、连接图、端口表和“方向图核对”。重点检查目标角、有效目标与输出峰的含义，并核对端口补偿相位；图中连接长度不代表实体馈线尺寸。

![直线阵馈电的参数与结果区域](images/workflow-feed.png)

需要看多个角度时，先选好已有设计，再点“多角度评估”。同一设计的扫描窗口关闭后再次打开，会保留本次会话里的设置和结果；主程序关闭后的恢复需要另按扫描功能的保存/导出方式处理，详见[扫描评估](scan-study.md)。

平面阵采用相同操作顺序，但在自己的右侧参数区设置布局、目标θ/φ和馈电。目标φ与观察切面φ分别设置；θ从+z轴量起，φ从+x朝+y。详见[平面阵指南](planar-arrays.md)。

![平面阵独立参数区与结果视图](images/workflow-planar.png)

## 保存怎么选

| 按钮 | 用于什么 | 下次怎么继续 |
| --- | --- | --- |
| 保存参数 | 保存当前任务输入，包括尚未计算的修改 | 打开参数，检查后按F5 |
| 保存记录 | 保存直线阵/直线阵馈电的已有结果、标签及选中项 | 打开记录，直接查看，不重算 |
| 导出当前结果 | 输出所选结果的数据或报告；直线阵按钮显示“导出所选曲线” | 在外部查看或处理 |

完整记录恢复目前只支持直线阵分析和直线阵馈电，每类文件最多5条。平面阵、二维稀疏使用各自的参数保存和结果导出。完整范围见[计算记录指南](calculation-history.md)。

## 图形或面板找不到时

“图形与布局”中的“保存当前图”“复制当前图”“重置图形”操作当前任务的图形；如果正在看数据表，先切换到图形视图。“模型视图”用于直线阵模型示意。右侧参数区可从“视图 → 显示当前参数区”打开；面板移乱了，点“视图 → 恢复工作布局”。消息默认收起，需要时从“视图 → 消息”查看。F1打开当前任务的操作说明。

右下角的并行选项影响之后启动的扫描、平面阵和稀疏复核计算。通常保留“自动（最多4路）”即可，细节见[多核说明](multicore.md)。当前电气模型的物理尺寸与误差统计继续暂缓。
