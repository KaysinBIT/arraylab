# 多扫描角电气评估（0.8.0）

本阶段用于比较同一阵列和馈电网络在多个扫描指令下的电气响应。每点重新设计端口补偿相位，阻抗主干、幅度加权、频率和负载保持不变。支持直线阵有符号θ扫描，以及规则矩形阵、任意x-y坐标平面阵的θ或φ扫描。

用户已明确暂缓误差统计和物理尺寸。本功能不做蒙特卡洛统计，也不把电长度换算成实体走线长度。

## 桌面操作

1. 在馈电电气页选定一项已生成的设计，或在平面阵页生成设计；原设计须启用“扫描补偿”。
2. 点击“扫描评估”，从该结果快照创建独立评估。主页面尚未重新计算的新输入不会混入。
3. 设置扫描轴、起止角及点数，点击“开始扫描”。角度等间隔且包含两个端点。
4. 查看目标方向响应曲线、扫描方向图总览，或选择某一点查看方向图和逐端口补偿电长度/输出相位。
5. “保存评估设置”保存当前评估输入；“导出扫描结果”保存上次成功扫描的完整快照。修改输入不会改变已有结果。

计算在后台顺序执行，显示完成点数。取消在当前扫描点计算完成后生效；取消、无效设置或加载失败保留旧结果。关闭窗口会先请求取消，再等计算结束，避免后台任务残留。关闭后的结果需要通过此前导出的文件保留。

“打开评估设置”可载入完整直线阵或平面阵扫描方案；载入后提示待计算，不会自动替换旧结果。起止角不合法、点数或总采样数超限会明确拒绝。

## 输入与坐标

| 项目 | 约定 |
| --- | --- |
| 扫描点数 | 2–200 |
| 直线阵θ | −90°至90°，从+z向+x为正 |
| 平面阵θ | 0°至90°，从+z轴量起；φ保持原设计值 |
| 平面阵φ | −180°至180°，从+x朝+y；θ保持原设计值 |
| 起止角 | 起始角严格小于终止角；扫描轴不可混用 |
| 方向图切面 | θ采样步长沿用源设计；平面阵切面φ固定为源设计值，可能不经过当前扫描方向 |
| 资源范围 | 扫描点数×切面采样数不超过100万；阵元数量与几何范围沿用单次设计 |

φ=−180°与180°指向相同的方位；θ=0时不同φ也代表同一方向，表中保留用户扫描指令，不宣称这些是不同波束。任意坐标阵的端口顺序决定网络连接，不自动按空间位置重新排序。

## 指标的含义

目标方向响应直接在当前扫描指令(θ,φ)处求复数场，使用目标激励的相干幅度和作为共同参考。不是在切面采样点上查找最近的值。指定方向的方向性定义为

\[
D(\theta,\varphi)=\frac{|F(\theta,\varphi)|^2}{(1/4\pi)\int|F|^2\,d\Omega}.
\]

全空间功率使用各向同性点源的sinc核，严重数值抵消时采用球面求积回退。该指标只描述**指定目标方向**，不是全空间最大方向性、增益、实际峰值位置或扫描指向误差。自定义相位偏置、量化或失效可能使峰值偏离指令；本版扫描表不计算峰值跟踪、HPBW或旁瓣电平。

同时输出目标方向幅度(dB)、输出/名义功率比、最大有源端口相位偏差，以及每个端口的目标相位、理想/量化后电长度、导波波长比例和输出复激励。功率比沿用既有扰动模型，不等同于被动网络效率。

若原设计设置了单次随机幅相误差，扫描全程使用同一随机种子和同一组阵元误差；量化位数及指定失效端口也固定，不重新抽样。全部端口失效时，方向性和端口输出相位为null；方向图以−300 dB作为数值下限。正常方向图数据不因显示下限−60 dB而截断。

## 配置、无头与导出

设置格式为`arraylab.electrical_study`、schema_version=1，包含阵列类型、全部几何参数、完整馈电设置及扫描设置。未知/缺失字段、未知版本、重复JSON键和非有限值会被拒绝；结果报告不能当成输入方案。

```powershell
ArrayLab-cli.exe --study scan --feed-config examples/feed-electrical.json --scan-start -60 --scan-stop 60 --study-count 13 --output-dir results/scan-line --plot all
ArrayLab-cli.exe --study scan --planar-config examples/planar-arbitrary.json --scan-axis phi --scan-start -90 --scan-stop 90 --study-count 19 --output-dir results/scan-plane --plot all
ArrayLab-cli.exe --study-config examples/scan-linear.json --output-dir results/replay --plot all
```

源码入口可替换为`python -m arraylab --headless`。使用`--study scan --help`查看专用选项；原电气设置中的参数需先在原设计中修改，扫描命令不会静默接受`--elements`等单次设计参数。扫描参数可显式覆盖保存的扫描方案，不修改原文件。`--plot`取none或all，PNG使用Agg渲染，不加载Qt。

新目录内导出：

- `study-config.json`：可重新计算的完整方案。
- `study-report.json`：源设计、所有扫描条件、公共阻抗网络、每点完整相位表/方向图/指标和模型边界。
- `study-metrics.csv`：逐扫描点的指令、种子及指标，未定义项为空。
- `study-ports.csv`：全部扫描点的逐端口电气数据，以scan_index和port关联。
- `study-001.dat`等：对应每个扫描点的无表头角度°、幅度dB两列，可在主工作台重新读入。
- `study.png`：目标方向响应图（桌面导出默认包含；无头通过`--plot all`启用）。

DAT使用12位有效数字。完整JSON保留坐标及归一化定义；单独导入DAT不能恢复网络或全空间方向性。结果在临时目录生成成功后才发布，已有目录不覆盖，失败清理本次临时文件。

本功能在中心频点修改理想匹配相移，不描述固定馈相随频率变化、真实器件调谐范围、互耦或实体馈线损耗。后续频率响应与反射分析需另行确定相应电气模型。
