# 子阵中心位置优化

该任务在固定数量的子阵之间调整二维中心位置。每个子阵采用相同的矩形内部模板，内部阵元数、间距、朝向及幅度保持不变。每个扫描角和频率工况独立设置子阵公共相位和内部阵元相位，使全部阵元对准该工况的目标方向。

这属于连续位置优化；没有从候选网格抽稀，也没有重新划分已有阵元。初版使用各向同性、等幅、独立阵元，不包含互耦、损耗、失配、实体尺寸或误差统计。子阵数量与实际阵元数量分别报告，不能据此推定端口数量或 RF 链数量。

## 从界面开始

1. 在 ArrayLab 的任务导航中选择“子阵中心优化”。
2. 在“子阵”页设置子阵数量及内部 X/Y 阵元数、间距。
3. 在“孔径”页设置总孔径、实际阵元最小间距以及中心禁布区。
4. 在“扫描”页设置参考频率与目标 θ、φ；需要联合优化时填写频率及角度列表。
5. 在“优化”页设置主瓣排除范围、搜索次数和网格密度，点击“优化子阵中心”。
6. 选择工况，查看布局、二维方向图、正交主瓣切面或三维方向图。图下显示该工况的方向性、波束宽度和空间采样 PSL。
7. 保存参数可复现输入；导出结果保存初始与最终布局、工况幅相、指标、球面数据和所选图形。

更改输入后需要重新计算。取消搜索不交付中间结果，保留原来成功完成的结果。当前页面显示的布局和指标来自已完成的计算快照。

## 参数定义

位置与间距统一采用参考频率的波长 λ₀。扫描频率变化时实际布局不改变。

| 参数 | 含义 | 默认值 / 范围 |
|---|---|---|
| `count` | 固定子阵数量 | 9；1–64 |
| `nx`, `ny` | 每个子阵内部 X/Y 阵元数 | 2、2；各 1–8；实际总阵元不超过 512 |
| `spacing_x`, `spacing_y` | 内部相邻阵元间距 / λ₀ | 0.5；0.01–10 |
| `aperture_x`, `aperture_y` | 包含全部实际阵元中心的矩形孔径 / λ₀ | 6、6；0.01–100 |
| `min_spacing` | 任意两个实际阵元之间的最小欧氏距离 / λ₀ | 0.5；0–10；0 仍禁止重合阵元 |
| `reference_ghz` | 定义 λ₀ 的参考频率 | 10；0.1–1000 GHz |
| `theta`, `phi` | 默认目标角；θ 从 +z 量起，φ 从 +x 朝 +y | 0、0；θ 0–60°，φ −360–360° |
| `frequencies_ghz` | 逗号分隔的频率列表；留空使用参考频率 | 空；频率/参考频率为 0.25–4 |
| `scan_angles` | 分号分隔的 θ,φ 列表；留空使用默认目标角 | 空；例如 `0,0;30,0;30,90` |
| `exclusion_u`, `exclusion_v` | 目标方向周围主瓣矩形排除区的半宽 | 0.2、0.2；0.005–1 |
| `iterations` | 每次独立搜索的最大尝试次数 | 200；1–20000 |
| `restarts` | 使用不同随机序列的独立搜索次数 | 2；1–8 |
| `opt_grid` | 优化用 u/v 方形采样网格边长 | 31；21–101 |
| `eval_grid` | 结果复核用网格边长，必须大于优化网格 | 81；41–301 |
| `seed` | 随机种子 | 42；0–2³²−1 |
| `hole_shape` | 中心禁布区形状 | `none`、`rectangle`、`circle` |
| `hole_x`, `hole_y` | 矩形宽/高，或圆直径 / λ₀；圆形仅使用 `hole_x` | 1、1；正数 |

最多联合 25 个角度与频率组合。频率列表与角度列表采用笛卡尔积，不是逐项配对。

总孔径边界、禁布区和最小间距均检查展开后的实际阵元中心。每个子阵内部阵元坐标的包络矩形不得重叠；退化为线段时也不得沿同一直线交叠。包络可以接触，但不能造成重合阵元或违反最小间距。这些约束描述阵元中心和模板关系，不代表基板、封装或馈线的实体间距。

## 目标与指标

优化目标是所有工况中，指定主瓣排除区外的最差采样 PSL。方向余弦为 `u = sin(θ)cos(φ)`、`v = sin(θ)sin(φ)`；计算范围是 `u²+v² ≤ 1` 的可见圆盘。副瓣电平相对于目标方向的相干峰值归一化。

主瓣排除区由用户明确设置，边界也被排除。它不是自动找到的首零点区域；范围过小会把主瓣裙边算入目标，范围过大可能漏掉需要评价的其他峰。优化过程不会自动扩大排除区。参数应与所需波束宽度和扫描范围一起审查。

求解采用有种子的中心坐标扰动和退火接受规则。每次试探都检查布局约束，保留搜索中的最佳候选。最终同时进行加密网格和半网格偏移复核；如果候选在这两个复核网格上的最差结果比初始布局更差，则交付初始布局并设置 `validation_reverted=true`。该机制不能保证连续域最优，不能替代更细采样或独立电磁分析。

每工况提供以下指标：

- **空间采样 PSL**：两个复核网格中更差的结果，并分别保存两次采样值。
- **峰值方向性 D（dBi）**：使用所有实际阵元及其相位的全空间辐射积分，目标方向达到等幅相干上界。
- **两条正交大圆切面的半功率宽度**：通过目标方向，分别采用子午与横向切面。显示的是相对该峰的半功率交点角距，无边界时不报告宽度。
- **增益 G**：缺少辐射效率数据，显示未计算。方向性没有改名为增益。

由于阵元位于 z=0 平面且为各向同性模型，上下半空间互为镜像；目标峰并不宣称唯一。目标方向偏差为 0 表示理想调相在该方向达到相干峰值，不排除其他等高峰。

报告给出最大电气孔径及采样步长。复核网格相对于孔径过粗时显示加密提示。提示所用的“每个 1/电气孔径尺度至少 8 点”是分辨率建议，不能构成连续域峰值保证。

## 无头使用

从源码目录运行，命令示例使用 Windows PowerShell：

```powershell
.\.venv\Scripts\python.exe -m arraylab --headless subarray --write-example .\my-subarray.json
.\.venv\Scripts\python.exe -m arraylab --headless subarray --config .\my-subarray.json --output .\output\subarray-run-01 --plot all --workers 0
```

输出目录必须尚不存在；失败时不会把未完成的暂存目录作为结果交付。已有配置文件不会被 `--write-example` 覆盖。

`--plot` 可选 `none`、`layout`、`pattern`、`cuts`、`3d`、`all`。无图形导出不需要 Matplotlib；任何模式均不需要 Qt 或显示服务器。

输出包含：

| 文件 | 内容 |
|---|---|
| `report.json` | 参数、初始/最终布局、各工况指标与相位、搜索轨迹、执行配置及限制 |
| `config.json` | 可再次运行的配置 |
| `initial-centers.csv`、`best-centers.csv` | 子阵编号、中心坐标，包含 λ₀ 与 mm 两种表示 |
| `*-case-N-elements.csv` | 各工况实际阵元坐标、子阵归属、内部编号、幅度与相位 |
| `case-metrics.csv` | 初始/最终各工况 PSL、方向性、正交波束宽度和指标口径 |
| `best-case-N-sphere.csv` | 最终布局的完整球面数据；θ/φ 均按 3° 采样，明确用于显示，不是指标搜索网格 |
| `subarray-*.png` | 按选项生成的图形，保留图下指标 |

Python API 使用 `SubarrayConfig` 和 `optimize_subarrays`。需要指定一个已知可行的初始布局时，可通过 `initial_centers` 传入 `count×2` 的中心坐标；GUI 和命令行默认自动构造初始布局。未能构造可行初始布局会明确报错，不解释为数学不可行证明。

## 多核与复现

多个独立搜索通过 ArrayLab 共享的有界线程池运行。`--workers 0` 为自动、`1` 为串行，显式值允许 2–8，并受到实际可用 CPU 与搜索次数限制。每个搜索的随机序列由种子和搜索编号确定；并行完成顺序不会改变选择结果。NumPy 的内部 BLAS 在此批计算期间限制为单线程，避免线程层层叠加。

预计算与最终布局复核也进入同一资源控制器，各阶段顺序调用而不嵌套。报告分别保存 `preparation_execution`、搜索的 `execution` 和 `validation_execution`；阶段结束恢复调用前的 BLAS 设置。单路模式覆盖这些数值阶段。

改变并行数而保持参数、软件版本和初始布局相同，可对比输出的一致性。结果复核与图形导出采用相同保存快照。搜索阶段仅保留分块场数据，避免为每个工作线程长期保留“全部采样点×全部子阵”的大矩阵。增加工况、网格或迭代次数仍会增加计算量。
